🛡️ Commercial launch readiness

Checking administrator permissions…

💳 Payments — not connected

There is no live checkout or connected payment provider on this marketplace. The existing payment simulation never charges cards.

  • Connect a payment provider through a trusted server-side integration; never place secret API keys in GitHub Pages.
  • Configure marketplace seller onboarding, payout accounts and identity verification.
  • Calculate tax, shipping and total amount on the server, not from browser cart prices.
  • Verify webhook signatures and handle retries, refunds, disputes and duplicate events.
  • Run sandbox end-to-end payments before allowing any real charges.

📡 Live video — not connected

Streaming requires a live-video service, secure host authorization, short-lived access tokens and viewer playback integration.

  • Set up a streaming provider and private server-side token issuer.
  • Restrict stream creation to approved sellers and enforce moderation/reporting.
  • Test microphone/camera permissions, iOS playback, network recovery and stream termination.
  • Implement chat, reactions and recording only after access controls are verified.

🔔 Notifications — in-app activity only

The Activity page currently refreshes account data. Push delivery requires explicit browser permission, subscription storage and a trusted delivery service.

🧪 Release gates

Before launch, test two separate accounts, seller approval, product visibility, inventory reservations, cancellation, refund scenarios, message privacy, support access, account recovery and mobile navigation.

This checklist is informational. Nothing here claims that payment, streaming or push notifications have been enabled.
