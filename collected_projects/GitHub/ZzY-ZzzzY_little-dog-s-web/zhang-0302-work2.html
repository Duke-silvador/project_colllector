♫ 社团简介

小提琴社是一个热爱弦乐、乐于交流的校园音乐社团。无论你已经掌握基础演奏，还是刚刚对小提琴产生兴趣，都可以在这里找到志同道合的伙伴。我们定期开展基础教学、合奏排练、作品分享和校园演出，让每一位成员都能在音乐中收获自信、友谊与成长。

社团坚持“兴趣为先、互助学习、共同进步”的理念。加入我们，不必担心起点不同，只要愿意倾听、练习与分享，就能在琴声中发现自己的闪光点。
