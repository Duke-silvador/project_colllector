为什么星星这么亮，是不是有人在想你啊？
哦~是我啊

展信安：

首先呢，祝你生日快乐。新年的起始点属于全人类，而这一天属于你。 总之，今天是一个值得把喜欢说得更认真一点的日子。

我们的相遇是一个偶然吗？我想不是。从刚刚加上微信，到后面的飞信传书，貌似都是一点点积累起来的缘分。于我而言，你是星星还是月亮？ 像星星一样一闪一闪，轻轻地来，悄悄地闪，留下一张纸条然后转身而去。还是像月亮，亮亮的，一直照着我。

我们高中的相处好像是一个小小的秘密，分你几个糖果，给我一个果冻。拍一拍肩膀，递出一封小小的信。仿佛在学习之余有了一丝不一样的色彩。

这个可爱的小学生，你可以大胆一点，可不可以多给我说一说不敢说出口的话，怎么这么傲娇呢？我们现在的关系是不是可以多粘我一下呢?我是不会嫌你烦的，某位自称本小王的家伙。 （os：每天撩一撩这个小学生好有意思啊。）你可以再自信一点，我也很喜欢跟你玩游戏的，听着你在峡谷里的自言自语，真的很可爱的。怎么逗一下就要说跟我绝交？信不信我真跑了..... 我的微信好像比别人的神奇一些，有倒霉熊的日常生活，也有傻傻的小学生的日常生活。你可以多发一些给我看，我会很开心的。 我还想跟你看一场电影，吃一顿饭，玩一些好玩的。好像真的要等到明年了呢。

继续续写这一场故事吧
