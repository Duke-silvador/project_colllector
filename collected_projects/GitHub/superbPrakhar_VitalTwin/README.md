# Project: superbPrakhar/VitalTwin

**Source:** GitHub

**Description:** VitalTwin is a patient digital twin fusing EHR records with real-time wearable telemetry on a calibrated physiology model. It mirrors each patient hourly, predicts adverse events ~18.5 h before onset (AUROC 0.784), and simulates treatments before prescribing — goal-seeking the smallest effective change. Explainable, deterministic, reproducible.
