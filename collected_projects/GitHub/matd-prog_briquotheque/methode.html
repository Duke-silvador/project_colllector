Comment est estimée la valeur de la collection
← Retour à l'appli

En résumé

  • La collection est estimée à ce que coûterait son rachat, au jour de l'estimation.
  • Les prix viennent des ventes réellement conclues sur BrickLink ces 6 derniers mois, en Europe, TVA comprise. Pour un set encore vendu par LEGO, c'est son prix LEGO.
  • Les figurines sont estimées une à une, car elles valent souvent plus que le set entier.
  • Un set garde une valeur pour ses briques, sa boîte et sa notice, même quand ses figurines valent plus que lui.
  • Rien n'est compté deux fois.
  • Les figurines personnalisées (customs) : prix du fabricant si elles sont encore vendues ; épuisées, le plus haut entre prix payé, dernier prix du fabricant et prix demandé sur eBay.de.
  • Une valeur déclarée (pièce signée, exemplaire rare) remplace l'estimation, avec sa justification.

1. Le principe : la valeur de rachat

La question posée est simple : si toute la collection disparaissait aujourd'hui, combien coûterait-il pour la racheter à l'identique ? C'est la valeur utile pour une assurance (valeur de remplacement). Elle est calculée à la date indiquée dans l'appli et dans le dossier, car les prix de la collection évoluent avec le temps.

L'appli donne aussi, pour information, la valeur d'occasion : ce qu'on retirerait en revendant la collection, ou ce que coûterait son rachat d'occasion. Elle est calculée de la même façon, avec les prix d'occasion.

2. D'où viennent les prix

BrickLink est la plus grande place de marché de LEGO au monde : des milliers de vendeurs y vendent figurines, sets et objets LEGO, neufs ou d'occasion. Chaque article y a une référence unique (par exemple sw0841 pour une figurine, 75192-1 pour un set), celle qui figure dans votre fichier.

  • Les prix de ventes réellement conclues sont retenus, pas les prix affichés par les vendeurs, qui peuvent être exagérés.
  • Sur les 6 derniers mois, pour refléter le marché actuel.
  • En Europe, TVA comprise, en euros : c'est le prix qu'un acheteur français paie réellement. Pour un article rare qui ne s'est pas vendu en Europe, les ventes du monde entier sont utilisées (c'est signalé).
  • Le prix du milieu (la médiane) est retenu : la moitié des exemplaires se sont vendus plus cher, la moitié moins cher. Une vente anormale (un lot, un set incomplet, une affaire ou un prix excessif) ne fausse donc pas l'estimation, comme le ferait une moyenne.
  • Prix neuf pour la valeur de rachat. Si un article ne s'est jamais vendu neuf ces 6 derniers mois, son prix d'occasion est retenu à la place (c'est signalé).

Sets encore vendus par LEGO : ils sont estimés à leur prix de vente public LEGO en France, puisque c'est ce que coûterait leur rachat. Le prix vient d'Avenue de la Brique (comparateur de prix français, qui affiche le prix public LEGO France de chaque set) ; les dates de sortie et de fin de vente viennent de Brickset, la base de référence des collectionneurs. Un set est considéré comme encore vendu tant que sa fin de commercialisation n'est pas passée. Sans prix français connu, le set est estimé comme un set retiré (ventes BrickLink).

3. Les figurines : estimées une à une

Chaque figurine a son propre prix de marché. C'est souvent elle qui fait la valeur d'un set : une figurine rare ou exclusive peut valoir à elle seule plus que tout le set dont elle vient. Dans la collection étudiée, sur 48 sets dont toutes les figurines ont un prix, 10 avaient des figurines qui valent plus que le set entier.

4. Les sets montés : figurines + reste du set

Estimer un set monté d'après le seul prix d'un set complet le sous-estime souvent, car ce prix est tiré vers le bas par des sets revendus incomplets ou sans leurs figurines. Un set est donc estimé en deux parties :

  • ses figurines, une à une, au prix du marché ;
  • le reste du set (briques, boîte, notice) : le prix du set moins la valeur de ses figurines. Quand les figurines valent presque autant que le set, ou plus, ce reste ne descend jamais sous 50 % du prix LEGO d'origine du set : les briques, la boîte et la notice gardent toujours une valeur. Ce minimum vient d'un test sur 57 sets vendus sans figurines sur eBay.de : demandés en médiane à 62 % de leur prix LEGO (la moitié entre 48 et 74 %).
  • Quand le même set est proposé sans figurines sur eBay.de (au moins deux annonces), le reste ne descend pas non plus sous 85 % du prix du milieu de ces annonces (un prix demandé est souvent un peu au-dessus du prix de vente réel).

Exemple : un set qui se vend 40 €, dont les 4 figurines valent 55 € à elles seules ; il coûtait 50 € chez LEGO à sa sortie.

Figurines, une à une55,00 €
Reste du set : 40 € − 55 € est négatif, donc le minimum de 50 % × 50 €25,00 €
Valeur retenue pour le set80,00 €

Avec le seul prix du set, il aurait été estimé 40 €.

Autre exemple : un set encore vendu 999,99 € chez LEGO, dont les figurines valent 546 €. Tant qu'un set est vendu par LEGO, le racheter coûte son prix LEGO, figurines comprises : le reste n'a pas de minimum.

Figurines, une à une546,00 €
Reste du set : 999,99 € − 546,00 €453,99 €
Valeur retenue pour le set (= prix LEGO)999,99 €

5. Rien n'est compté deux fois

Quand une figurine d'un set est aussi rangée dans les onglets de figurines de la collection, elle est comptée une seule fois, avec les figurines. Elle est alors déduite du set, qui ne compte plus que son reste (briques, boîte, notice). Chaque exemplaire ne sert qu'une fois : si vous avez deux fois la même figurine, les deux sont comptées. Les lignes en double dans l'onglet des sets sont signalées par l'appli pour être supprimées.

6. Les autres cas

  • Sets neufs scellés : prix des ventes de sets neufs (ou prix LEGO s'ils sont encore vendus). Leurs figurines, encore dans la boîte, ne sont pas estimées à part.
  • Figurines des séries à collectionner (Simpsons, Disney, Looney Tunes…) : prix de chaque figurine.
  • Objets dérivés LEGO (porte-clés, porte-clés lumineux, magnets…) : prix BrickLink, neuf ou d'occasion selon leur état.
  • Figurines personnalisées (« customs »), par exemple celles de JB Spielwaren : elles ne sont pas des produits LEGO et n'ont pas de place de marché comme BrickLink.
    • Encore en vente chez leur fabricant : son prix de vente actuel (coût de rachat).
    • Épuisées (plus en vente chez le fabricant) : on ne peut plus les racheter qu'à d'autres collectionneurs. La valeur retenue est la plus haute entre le prix d'achat (frais de port compris, justifié par les reçus et l'historique Whatnot), le dernier prix de vente du fabricant et le prix demandé sur eBay.de (prix du milieu, quand au moins deux annonces sont en ligne).
    • Chaque exemplaire garde son propre prix d'achat. Une custom achetée dans un lot de vente en direct dont le nom n'est pas indiqué prend son prix payé, ou le prix habituel d'une custom dans cet historique (médiane des lots achetés).
  • Autres marques de briques (Youmko, Pantasy, Reobrix, Cobi, BlueBrixx, CaDA, Mould King…) : absentes de BrickLink, elles sont estimées d'après les annonces eBay France du même article (marque et numéro dans le titre, lots, notices seules et kits d'éclairage écartés) : prix du milieu pour le rachat, 85 % pour l'occasion, quand au moins deux annonces sont en ligne. Sinon, c'est le prix payé indiqué lors de l'ajout qui est retenu. Si le fabricant vend encore le set sur son site, son prix affiché pour la France (indiqué lors de l'ajout) sert de coût de rachat, comme le prix LEGO d'un set encore en vente. Ces marques ne vendent que des sets : leurs rares figurines sont des accessoires, non estimées à part.
  • Valeurs déclarées : pour une pièce exceptionnelle (figurine signée, exemplaire rare…), le propriétaire peut déclarer une valeur, avec sa justification (certificat, photo de la signature, vente comparable). Elle remplace alors l'estimation pour le nombre d'exemplaires indiqué, et le dossier l'indique comme « valeur déclarée ».
  • Articles sans aucune vente sur 6 mois : listés à part, sans valeur.

7. Mise à jour des prix

Les prix sont relevés automatiquement chaque mois, et à chaque demande depuis l'appli (« Envoyer ma liste »). Un prix BrickLink relevé depuis moins de 25 jours n'est pas redemandé ; les prix LEGO sont vérifiés chaque semaine. La date des prix est indiquée dans l'appli et dans le dossier. Les prix et la disponibilité des customs JB Spielwaren, et les prix demandés sur eBay.de, sont relevés à la demande.

8. Prix de revente et doubles à vendre

Ces prix ne changent pas la valeur de la collection : ils servent à revendre les exemplaires en double.

  • Prix de revente conseillé (écran « Mes achats customs ») : le prix de vente qui rend le prix payé plus la marge voulue, une fois retirés les frais de la plateforme de vente :
    prix de revente = (prix payé × (1 + marge) + frais fixes) ÷ (1 − frais en %), arrondi à l'euro supérieur. Les frais et la marge sont réglables (par défaut 11 % + 0,30 € de frais, 20 % de marge).
  • Prix demandé sur eBay.de : prix du milieu des annonces à prix fixe en cours pour la même figurine (hors lots), avec le nombre d'annonces. Ce sont des prix demandés, pas des ventes conclues : une seule annonce est un repère fragile.
  • Liste « À vendre » : pour chaque figurine en plusieurs exemplaires (d'après votre base de blisters), le numéro le plus bas est gardé, ainsi que les exemplaires qui ont une note (signé, Comic Con…) ; les autres sont à vendre. Prix proposé : le plus haut entre le prix de revente conseillé et le prix demandé sur eBay.de, sans dépasser le prix du fabricant si la figurine y est encore vendue.

Exemple : une figurine payée 21,25 € (port compris), frais 11 % + 0,30 €, marge 30 %.

À récupérer : 21,25 € + 30 % + 0,30 €27,93 €
Prix de vente : 27,93 € ÷ (1 − 11 %)31,38 €
Prix de revente conseillé (arrondi)32,00 €

9. Où voir chaque valeur dans l'appli

  • Valeur : valeur de rachat à neuf de la collection (et d'occasion), par onglet et par catégorie ; pour chaque article, la source du prix (BrickLink, prix LEGO, prix JB, prix d'achat, eBay.de, valeur déclarée).
  • Dossier assureur : la même valeur, article par article avec sa source, et cette méthode.
  • Mes achats customs : prix payé de chaque exemplaire, prix de revente conseillé, prix eBay.de, liste « À vendre ».
  • Consulter la base : prix JB des figurines encore vendues, et « Épuisée chez JB (était à … €) ».

10. Les limites de l'estimation

  • C'est une estimation fondée sur le marché, pas une expertise article par article : l'état réel de chaque pièce (usure, pièce manquante) n'est pas vérifié.
  • Pour un article très rare, peu de ventes existent : son prix est moins sûr (le nombre de ventes est indiqué dans le dossier).
  • Les prix de collection évoluent : une estimation récente est plus fiable.
  • Les customs achetées en lot sans nom (vente en direct) sont comptées à leur prix payé tant qu'on ne sait pas quelle figurine c'était ; une fois nommées, elles suivent la règle des customs.
  • Une valeur déclarée n'a de poids que si elle est justifiée (certificat, photo de la signature, vente comparable).
