07 / IMPORTANT TO KNOW

안전하다는 말보다,
무엇을 보호하는지
명확하게.

SecureBox는 메일에 첨부된 암호문만 유출된 경우 파일 내용의 기밀성을 보호하도록 설계됩니다. 모든 해킹을 막거나 이미 열린 문서를 회수하는 기술은 아닙니다.

01

첨부 내용 보호

별도 복호화 비밀이나 키가 유출되지 않았다면, 탈취한 `.sec`만으로 원문을 열 수 없도록 설계합니다.

02

이메일 메타데이터는 보호 범위 밖

수신자 주소, 메일 제목, 전송 시간, 첨부 크기 등은 암호화하지 않습니다.

03

열린 평문은 별도 보호가 필요

수신자 기기 악성코드나 이미 복호화한 파일의 복사는 첨부 암호화만으로 막을 수 없습니다.

08 / FAQ

자주 묻는 질문.

서비스 기능은 단계별로 출시될 예정이며, 현재 페이지는 제품 기획을 소개하는 홍보용 데모입니다.

계약서를 보내려면 Gmail 대신 다른 이메일이 필요한가요?+

아니요. SecureBox에서 암호화된 `.sec` 파일을 준비하고 Gmail, Outlook 등 평소 사용하는 메일 서비스에 첨부하는 방식입니다.

PDF 계약서는 모두 유료인가요?+

아니요. PDF와 DOCX 등 모든 파일의 기본 로컬 암호화와 이메일 .sec 첨부는 무료입니다. 본인 인증·기간 제한이 포함된 관리형 계약서 전송만 $4.90/건의 별도 유료 옵션입니다.

수신자도 유료 구독이 필요한가요?+

아니요. Personal 무료 앱으로 비밀번호 기반 복호화가 가능하도록 계획되어 있습니다. 기업 공동승인 파일은 해당 조직의 승인 정책을 따라야 합니다.

비밀번호를 같은 이메일로 보내도 되나요?+

권장하지 않습니다. 메일함이 함께 탈취되면 파일과 비밀번호가 모두 유출됩니다. 전화나 별도로 확인된 채널을 사용하세요.

관리자 승인 기간이 끝나면 이미 연 계약서도 못 보나요?+

기업용의 시간 제한은 서버가 새 키 조각을 발급하는 것을 막습니다. 이미 정상적으로 복호화해 보관한 평문이나 확보한 키의 재사용까지 완전히 차단하는 것은 아닙니다.

Windows나 Mac에서 카카오톡으로도 자동 암호화해 보낼 수 있나요?+

Team·Business에서 SecureBox의 보안 공유 기능을 이용하면 파일을 먼저 .sec로 암호화합니다. OS 공유 대상으로 지원되는 앱은 암호문 전달을 시도하고, 카카오톡 PC처럼 직접 첨부 API가 확인되지 않은 앱은 사용자가 완성된 .sec 파일을 채팅에 첨부합니다. 사용자가 SecureBox를 거치지 않고 원본을 직접 첨부하는 동작까지 막지는 못합니다.

Team과 Business는 몇 대의 기기에서 동시에 로그인할 수 있나요?+

Team은 PC 또는 모바일 중 1대, Business는 PC 1대와 모바일 1대를 동시에 쓸 수 있도록 계획되어 있습니다. 추가 기기는 기존 세션을 해제하고 본인 확인 후 이전합니다. 자동 보안 공유는 구독·기기 세션 온라인 검증이 필요합니다.

휴대폰을 분실해도 업무 파일이 안전한가요?+

Business 상시 암호화 보관함은 파일을 평소부터 암호문으로 저장합니다. 정상 모바일 열람은 생체 인증과 짧은 온라인 세션으로 허용합니다. 분실 시 등록된 Windows/macOS PC에서 서명된 원격 잠금으로 신규 키 접근을 차단하며, 잠금 해제는 PC 서명·MFA·기업 관리자 승인으로만 허용합니다. 휴대폰이 오프라인이어도 암호문은 유지되지만 이미 발급된 기존 키·열린 평문·클라우드 복사본은 즉시 회수할 수 없습니다. 오프라인에서 새 복호화는 허용하지 않으며 스마트폰 전체 잠금이나 완전 삭제는 지원하지 않습니다.

복호화 이력은 누가 확인할 수 있나요?+

Team·Business에 출시 예정인 기능입니다. 기업 관리형 파일의 복호화 요청, 승인, 복호화 완료, 복호화 실패를 PC·모바일에서 조회합니다. 본인은 자신의 이력을, 허가된 관리자는 소속 조직 이력만 확인합니다. 암호화 키·비밀번호·파일 내용·원본 경로는 기록하지 않습니다. 인터넷 연결이 필요하며 오프라인 Personal 복호화는 서버 이력에 포함되지 않습니다. 이벤트 전송 또는 기록이 실패하면 복호화 완료로 표시하지 않습니다.

발신자가 복호화를 중지하거나 ID로 파일을 보낼 수 있나요?+

Team·Business 출시 예정 기능입니다. 파일별 자물쇠로 허용·비허용을 선택하고 감사 이력에서 파일 검색·다중 선택으로 일괄 변경할 수 있습니다. 이미 발급된 키나 복호화된 평문은 회수할 수 없으며 향후 온라인 키 발급을 제한하는 방식입니다. 가입된 수신자의 ID를 확인해 암호화 파일을 전송하고 모바일·PC 알림을 보냅니다. Android/iOS의 백그라운드 알림은 보장되지 않으므로 앱 복귀 시 받은 파일함을 다시 동기화합니다. SecureBox.md는 SecureBox.sec로 저장하되 원래 확장자를 암호화된 메타데이터에 보관합니다.

.sec 파일을 받았는데 SecureBox 앱이 없으면 어떻게 하나요?+

SecureBox가 설치되지 않은 기기에서는 .sec 파일을 직접 복호화할 수 없습니다. 수신자에게는 공식 SEC 파일 열기·설치 안내를 함께 전달하도록 준비하고 있습니다. 설치 후 파일 연결을 통해 열며, 무료 비밀번호 기반 복호화는 가입 없이 이용하도록 설계합니다. 현재 앱은 출시 준비 중으로 다운로드를 제공하지 않습니다. 출처를 알 수 없는 프로그램을 설치하거나 암호를 알려주지 마세요.

iPhone과 Android에서도 사용할 수 있나요?+

Windows/macOS 개인용을 먼저 출시한 뒤 Android/iOS에서 `.sec` 수신·복호화부터 지원할 계획입니다. 모바일 앱은 아직 출시되지 않았습니다.
