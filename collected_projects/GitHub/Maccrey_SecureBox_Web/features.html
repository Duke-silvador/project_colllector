사용 방법과 보안 범위를 명확히 안내합니다. 항상 암호화 정책은 SecureBox가 수행하는 내보내기와 공유에만 적용됩니다. 기업 관리 PC의 시스템 전체 반출 통제는 별도 보안 제품과 장치 관리 정책이 필요합니다.

익숙한 이름의 암호화 파일

예를 들어 SecureBox.md를 암호화하면 SecureBox.sec로 저장합니다. 복호화할 때 원래 파일 이름과 확장자를 복원합니다.

이름이 겹치면 덮어쓰지 않고 확인하며 파일 이름의 일부가 노출될 수 있습니다. 보다 엄격한 익명 이름 옵션도 제공할 계획입니다.

복호화 이력, PC·모바일에서 확인

누가 어떤 보호 파일에 접근했는지, 언제 복호화 요청이 있었는지 PC와 모바일 SecureBox에서 확인하도록 준비하고 있습니다. 내 이력과 권한에 맞는 조직 관리 이력을 구분하며 요청·승인·완료·실패를 쉽게 살펴볼 수 있습니다.

기업 관리형 복호화의 이력은 온라인 연결이 필요하며, 무료 개인용 오프라인 복호화는 서버 감사 기록을 제공하지 않습니다. 기능은 출시 전 기획입니다.

안전한 최신 버전 안내

Windows와 macOS는 서명된 업데이트를 확인하고, Android와 iOS는 공식 앱 스토어 업데이트를 이용합니다.

  1. 새 버전 및 보안 중요도 확인
  2. 배포처와 무결성 검사
  3. 진행 중인 암호화 작업 종료 후 적용
  4. 기존 .sec 파일·키 및 설정 호환성 유지

업데이트는 사용자의 네트워크·설정·스토어 정책에 따라 지연될 수 있습니다. 모바일 앱을 몰래 강제 설치하거나 저장된 원본 파일을 삭제하지 않습니다.
