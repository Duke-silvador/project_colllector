01

파일 선택

계약서 PDF나 폴더를 SecureBox에 추가합니다. 원본 파일은 그대로 유지됩니다.

메일에는 `.sec`만 넣고, 복호화 비밀은 전화 등 별도 채널로 전달합니다.
