SecureBox.sec 파일을 받으셨나요?
여는 방법을 알려드릴게요.

SecureBox의 .sec는 보호된 파일입니다. 앱이 설치되지 않았다면 파일을 열 수 없습니다. 설치 후에는 파일을 SecureBox로 열 수 있도록 준비하고 있습니다.

파일 열기 순서 보기 ↓주요 기능 알아보기 →

현재 앱은 출시 준비 중이며 다운로드·설치가 아직 제공되지 않습니다. 실제 설치 버튼은 서명된 정식 앱이 공개된 뒤에만 제공할 예정입니다.

RECEIVE / INSTALL / OPEN

파일은 그대로 보관하고,
공식 앱으로 열어 주세요.

받은 파일을 실행 파일로 바꾸거나 비밀번호를 제3자에게 전달할 필요가 없습니다. 파일을 보관한 뒤 공식 앱 설치와 파일 열기 절차를 확인하세요.

01

.sec 파일 안전하게 보관

이메일 또는 메신저로 받은 SecureBox.sec를 삭제하지 말고 안전한 위치에 저장하세요.

02

공식 앱 설치 확인

정식 출시 후 이 안내 페이지에서 운영체제별 서명된 설치 경로를 제공할 예정입니다. 현재 앱 설치는 지원되지 않습니다.

03

SecureBox로 파일 열기

설치 후 .sec 파일을 더블클릭하거나 파일 앱의 ‘공유·다음으로 열기’에서 SecureBox를 선택할 수 있도록 개발합니다.

04

복호화 후 원래 문서 확인

무료 비밀번호 방식은 가입 없이 열고, 관리형 기업 파일은 수신자 인증과 발신자 승인 정책을 확인합니다.

FOR THE SENDER

보내는 분께도 한 가지 안내가 있어요.

향후 SecureBox에서 .sec 파일을 이메일·메신저로 전송할 때 공식 SecureBox 파일 열기 안내 링크를 파일과 함께 전달하도록 준비합니다. 파일만으로 앱 설치 화면이 자동 실행되지는 않습니다.

설치 안내와 함께 평문 파일, 비밀번호, 암호화 키는 전송하지 않습니다. 비밀번호가 필요한 파일이라면 별도로 확인된 채널을 사용하세요.
