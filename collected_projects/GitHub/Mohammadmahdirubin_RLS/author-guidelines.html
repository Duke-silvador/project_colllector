نشریه مقالات را به سه زبان فارسی، انگلیسی و روسی می‌پذیرد. از نظر نوع، «مقاله پژوهشی اصیل» و «مقاله مروری / مرور کتاب» در صورت انطباق با حوزه و سیاست‌های نشریه قابل بررسی هستند. نویسندگان می‌توانند بر اساس زبان مقاله، تمپلت مربوط را دریافت و تکمیل کنند.

در راهنمای نویسندگان، دامنه موضوعی نشریه، انواع قابل ارسال، شرایط اصالت و ارسال، فایل‌های موردنیاز، ساختار پیشنهادی مقاله، شیوه استناد (APA ویرایش هفتم)، اخلاق پژوهش و چک‌لیست پیش از ارسال به‌صورت یکپارچه آمده است.

فایل اصلی مقاله باید بدون مشخصات شناسایی‌کننده نویسندگان ارسال شود تا داوری ناشناس حفظ گردد. مشخصات کامل نویسندگان و اطلاعات کتابشناختی در مراحل ارسال مقاله در سامانه OJS ثبت می‌شود.

پس از مطالعه راهنما و تکمیل فایل‌ها می‌توانید از صفحه ارسال مقاله اقدام کنید.

تعداد کلمات مقاله

  • مقالات پژوهشی: حداقل ۳۰۰۰ و حداکثر ۷۰۰۰ کلمه، بدون احتساب چکیده و فهرست منابع.
  • مقالات مروری یا موارد استثنایی: تا ۹۰۰۰ کلمه.

تعداد منابع و ارجاعات

  • مقالات پژوهشی: حداقل ۱۵ و حداکثر ۴۰ منبع.
  • مقالات مروری: تا ۶۰ منبع.

اعتبار، ارتباط و کیفیت منابع، مهم‌تر از صرف تعداد آن‌هاست.

استفاده از منابع جدید و به‌روز

به‌روز بودن منابع، متناسب با موضوع مقاله، الزامی است. برای موضوعات معاصر، دست‌کم نیمی از منابع باید مربوط به ۱۰ سال اخیر باشد. برای موضوعات کلاسیک که منابع قدیمی اهمیت علمی دارند، استفاده از منابع معتبر قدیمی نیز مجاز است.

میزان مشابهت مقالات با منابع دیگر

  • حداکثر مشابهت کلی مقاله: ۱۵ درصد.
  • حداکثر مشابهت با یک منبع: ۵ درصد.

ابتدا گزارش مشابهت مقاله بررسی می‌شود. اگر مشکل قابل اصلاح باشد، مقاله برای اصلاح به نویسنده بازگردانده می‌شود. در صورت احراز سرقت علمی، مقاله رد می‌شود و موضوع مطابق مقررات نشریه پیگیری خواهد شد.

اعلام تعارض منافع

اعلام تعارض منافع برای همه مقالات الزامی است.

سیاست استفاده از هوش مصنوعی

  • استفاده از هوش مصنوعی صرفاً به‌عنوان ابزار کمکی برای ویرایش زبانی، ترجمه و بهبود نگارش مجاز است.
  • استفاده از هوش مصنوعی برای تولید محتوای علمی اصلی یا تحلیل‌هایی که مسئولیت علمی آن‌ها بر عهده نویسنده است، بدون اعلام شفاف مجاز نیست.
  • نویسنده موظف است میزان و نحوه استفاده از هوش مصنوعی و نام ابزار مورد استفاده را هنگام ثبت مقاله در سامانه OJS اعلام کند؛ برای نمونه: «ChatGPT، نسخهٔ …؛ استفاده صرفاً برای ویرایش زبانی و ترجمه متن».
  • مسئولیت کامل صحت محتوای مقاله بر عهده نویسنده است. هوش مصنوعی به‌عنوان نویسنده شناخته نمی‌شود.

تعیین درصد مجاز استفاده از هوش مصنوعی

درصد ثابتی به‌عنوان حد مجاز تعیین نمی‌شود؛ ملاک اصلی، شفافیت، مسئولیت‌پذیری نویسنده و ماهیت کمکی استفاده از هوش مصنوعی است. با استفاده غیرمجاز و اعلام‌نشده از هوش مصنوعی، مطابق آیین‌نامه نشر برخورد می‌شود.
