Digital Preservation

حفظ و آرشیو دیجیتال

رویه‌های حفظ دسترسی و تمامیت محتوای منتشرشده.

هدف

نشریه تلاش می‌کند نسخه‌های منتشرشده مقالات، شماره‌ها و فراداده‌های مرتبط را به‌صورت پایدار و قابل دسترس نگهداری کند.

وضعیت فعلی

مخزن GitHub نشریه برای مدیریت و پشتیبان‌گیری عملیاتی فایل‌های وب و محتوای انتشار استفاده می‌شود؛ با این حال، GitHub به‌تنهایی به‌عنوان آرشیو دائمی و مستقل نشریه معرفی نمی‌شود.

آرشیو بلندمدت

نشریه پس از انتخاب و استقرار یک سرویس رسمی حفظ دیجیتال، نام سرویس و دامنه پوشش آن را در این صفحه اعلام خواهد کرد. تا آن زمان، اطلاعات آرشیو دائمی یا سرویس‌هایی مانند CLOCKSS یا Portico به‌عنوان فعال معرفی نمی‌شوند.

تمامیت سابقه علمی

در صورت اصلاح یا بازپس‌گیری مقاله، نسخه و سابقه مرتبط باید به‌گونه‌ای ثبت شود که وضعیت مقاله برای خوانندگان روشن بماند. اصلاحات و اطلاعیه‌های پس از انتشار مطابق سیاست مربوط اعلام خواهند شد.

برنامه توسعه

هم‌زمان با توسعه زیرساخت انتشار، نشریه برای آرشیو مستقل بلندمدت و استانداردسازی فراداده‌های انتشار اقدام خواهد کرد.
