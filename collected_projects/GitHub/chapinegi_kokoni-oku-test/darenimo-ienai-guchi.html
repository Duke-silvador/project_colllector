「話せる人がいない」と「話したくない」は別

相談相手がいても、内容によっては話したくないことがあります。相手との関係が変わりそう、心配をかけそう、説明するほどでもない。理由はひとつでなくて構いません。

誰かに見せる文章ではないので、きれいにまとめる必要はありません。矛盾していても、感情的でも、そのまま書けます。

固有名詞は置き換える

「夫」「友人A」「職場の人」のように書けば十分です。個人を特定できる情報や秘密情報は、できるだけ入力しないでください。
