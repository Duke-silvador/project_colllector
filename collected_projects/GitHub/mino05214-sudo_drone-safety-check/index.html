3. 👥 사람이 많은 곳 주의
인구밀집지역이나 사람 위에서 위험한 방식으로 비행하지 마세요.
4. 🚫 음주 상태 비행 금지
음주 상태에서는 조종하지 마세요.
5. 📦 위험물 투하 금지
비행 중 위험한 낙하물을 투하하지 마세요.
