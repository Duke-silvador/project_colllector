기사 읽기와 탐험하기

기사 읽기에서는 오른쪽 패널의 설명을 하나씩 열며 기사를 분석합니다. 탐험하기에서는 같은 기사를 보며 객관식 퀴즈를 풀고 정답과 해설을 확인합니다. 선생님 편집실에서 각 블록의 퀴즈를 추가하거나 수정할 수 있습니다.

퀴즈 선택과 풀이 결과는 현재 열린 페이지에서만 유지되며, 페이지를 새로고침하면 초기화됩니다.

인터넷 주소로 접속할 때

이 주소를 즐겨찾기에 추가해 주세요. 사이트 디자인과 기능이 업데이트되면 같은 주소에서 새로고침해 이용할 수 있어요. 최신 화면이 보이지 않으면 Ctrl+Shift+R (Mac: ⌘+Shift+R)을 눌러 주세요.

수정한 기사는 어디에 저장되나요?

선생님 편집실에서 바꾼 기사와 학습 설명은 현재 기기·브라우저에 자동 저장됩니다. 사이트 디자인이 업데이트되어도 저장한 기사 내용은 유지됩니다.

다른 기기와 학생에게 같은 기사를 전달하려면 JSON 내보내기/가져오기를 이용해 주세요. 편집한 내용이 인터넷의 모든 사용자에게 자동 공개되는 기능은 없습니다.

인터넷 없이 수업할 때

편집실의 ‘수정한 사이트 파일 저장’으로 오프라인 수업 파일을 보관할 수 있어요. 온라인으로 사용할 때는 매번 파일을 받을 필요가 없습니다.
