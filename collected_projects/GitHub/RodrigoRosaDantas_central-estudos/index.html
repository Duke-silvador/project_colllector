Como interpretar estes dados

Disponibilidade é uma tentativa técnica de alcançar o site agora. Falha de rede vira “não verificado”, não uma conclusão de que o projeto caiu.

Publicação técnica é o último push público conhecido no GitHub. Não representa estudo realizado, progresso ou desempenho.

Deploy usa o workflow público de publicação mais recente quando ele pode ser identificado. Se a API estiver limitada, a Central preserva o último dado conhecido e o marca como cache.
