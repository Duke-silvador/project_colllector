# Project: atahan99/proxmox-infra-iac

**Source:** GitHub

**Description:** Proxmox VE infrastructure as code for VMs, LXCs and digest-pinned Docker Compose stacks using OpenTofu, Ansible and CI-gated, pull-based Dockhand GitOps; GitHub Actions, Renovate, Gitleaks and Trivy for DevSecOps; Traefik, Authelia and Tailscale for private access; Prometheus, Grafana and Loki for observability; Proxmox Backup Server for recovery.
