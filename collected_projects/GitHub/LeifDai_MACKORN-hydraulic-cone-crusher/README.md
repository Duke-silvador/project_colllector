# Project: LeifDai/MACKORN-hydraulic-cone-crusher

**Source:** GitHub

**Description:** mining industry vertical-domain MACKORN cone crusher plugin: MACKORN NH/NS hydraulic cone crushers, comparable to Sandvik CH/CS and Metso HP/MP.
