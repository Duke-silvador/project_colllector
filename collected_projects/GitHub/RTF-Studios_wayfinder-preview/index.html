✎ Learn · Typography Is a Design Tool

Typography is how letters and text are selected and arranged to communicate. It helps a reader know what to read first, how to read comfortably, and which pages belong to the same book.

Vocabulary worth using correctly
  • Typeface/font: The appearance of letters; a typeface family such as Georgia or Arial.
  • Serif: A typeface with small finishing strokes on letters (for example, Georgia).
  • Sans serif: A typeface without those finishing strokes (for example, Arial).
  • Hierarchy: Using size, position and weight to show what matters first.
  • Alignment: Where text lines up: left, center or right.
  • Line spacing: The space between lines; helps words breathe.
  • Consistency: Using the same formatting rules for the same type of text across pages.
Big idea 1 — there is no magic best font. A serif typeface can feel like a classic story; a sans serif can feel friendly and contemporary. Both can be readable. Choose based on the reader and purpose, not just taste.
Big idea 2 — jobs need different sizes. The title might be large and bold. Story sentences should be large enough for a young reader, but not so big that half the story is pushed away.
Big idea 3 — limit the system. Start with ONE body-text font and ONE title font (they can be the same). Too many fonts make one book look like unrelated pages.

▣ Perform · Build Your Book's Type System

Continue in the same Google Slides storybook you opened during Practice. Keep your original story, slide order and illustration placeholders. Today is for TEXT, not images or proofing.

  1. Choose a readable body font. Select one serif OR sans-serif family for story sentences. Test it on one page at presentation size.
  2. Choose title formatting. Set a larger title font or weight for the cover. Keep author and publisher credits readable but secondary. You may use the same font family in different sizes.
  3. Format two consecutive story pages. Give both pages the same body font and a similar size, alignment and line spacing. Keep the original wording and illustration placeholders.
  4. Make your rule repeatable. On the Book Plan or a small working note, write: “Body: ___ font, ___ size, ___ alignment. Cover title: ___ font, ___ size.” Continue formatting additional pages as time allows.

Goal for today: At least TWO consistently formatted story pages and an intentionally formatted cover. A complete book, finished images and final proofreading are NOT required.

✎ Learn · Fix the Actual Formatting Problem

Different symptoms need different tools. A font menu changes letter style; font size changes how large letters appear; alignment changes where the text sits; line spacing changes the gap between lines. Those tools are NOT interchangeable.

Problem A · cramped lines

The little monster waited beneath the stairs. The room was silent. Then someone whispered its name.

The letters are readable, but the lines feel crowded.

Problem B · scattered formatting

The little monster waited.

The room was silent.

Then someone whispered its name.

A single paragraph uses unrelated sizes, typefaces and alignment.

Possible fixes: Problem A: adjust line spacing while preserving a readable size. Problem B: select one body-text rule and apply it consistently. Changing the color would not fix either issue.

✎ Learn · Consistency With a Purpose

A book can use a bold cover title and gentle story text and STILL be consistent: each kind of text follows a rule. Consistency does not mean every word looks identical.

Three story pages from the same book: Look at the actual text examples below. They show the SAME kind of writing—normal story sentences, not titles or special messages. Compare the letter shapes and sizes.

PAGE 1 · Georgia · 21 pt

The little monster opened the door.

PAGE 2 · Georgia · 21 pt

A warm light filled the hallway.

PAGE 3 · Arial · 13 pt

Someone had left a note beside the stairs.

All three samples show their fonts at roughly the labeled proportions for the screen. You do not need to build these pages in Slides to compare them.

Publisher's rule: Make a small set of choices you can apply repeatedly. Before making exceptions, ask what the exception communicates.
