H1Z2Z2-K Single Core Solar Cable

IEC 62930 compliant single-core black PV cable for DC string connections. TUV EL 23 A approved, XLPO insulated, suitable for harsh outdoor environments.

Temperature-40°C to +120°C
CertificationsTUV EL 23 A, IEC 62930

Applications

H1Z2Z2-K cable is the industry standard for DC string connections between solar modules. It connects individual PV panels in series to form a string, and strings are then connected to combiner boxes or inverters.

  • String connections between PV modules
  • DC side connections in solar arrays
  • Ground mount and rooftop installations
  • Utility-scale solar farms
