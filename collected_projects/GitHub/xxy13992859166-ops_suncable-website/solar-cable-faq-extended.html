What is the difference between PV1-F and H1Z2Z2-K?

PV1-F is a dual-core cable (red/black) for PV module to inverter connections. H1Z2Z2-K is single-core for DC string connections between panels. Both use XLPO insulation rated -40°C to +120°C.
