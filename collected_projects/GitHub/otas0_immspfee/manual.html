Language

The Lab shell supports zh / en / ja / ko / es / fr / de via the sidebar language select.

  • URL: ?lang=en (etc.) wins over localStorage key physics-lab-locale-v1, then syncs both ways.
  • html.lang: updated on switch for assistive tech (e.g. zh-CN, en, ja).
  • Focus: after a language change, focus returns to #locale-select.
  • Model titles: lazy packs data/locales/models-en.json / models-ja.json (npm run gen:model-locales). Other locales fall back to catalog source strings.
  • Repo policy: README / docs / new UI chrome are English-first; see AGENTS.md.

0. 架构原则（统一接口 · Canvas）

  • 对齐 scikit-complexity：catalog 分类 + 同一套 Model API；可视化层用 Web/Canvas，不依赖 Python/Rerun。
  • 物理交互借鉴 PhET / oPhysics / SimuPhysics（拖物、读数对照、虚像虚线）。
  • CS 步进/高亮借鉴 Algorithm Visualizer / eigenvue 思路（图算法点选连边、网表拖线）。
  • 工业级硬规则：每个模型须有权威来源与适用假设、高自定义参数；概念不符则修或下架。保真度 engineering（假设内可对照文献）与 principle（原理示意，非工业求解器）在壳层芯片上区分。详见 model-correctness · 伦理审计 · 手写优先队列。

1. Live vs Reinit（改参语义）

类型判定行为示例
Live（即时）paramSchema.group = dynamics / display / custom写回 params，下一帧立刻用新值；高度/相位不跳回g, k, m, μ, R, C, 学习率
Reinit（重置）group = initial / numerics保留 params 后 init()，仿真状态重建；toast「已重置仿真状态」h₀, x0, v0, θ0, seed, n

工作台顶栏：「动力学即时生效；初值/数值会重置状态」。行标记 即时 / 重置。已取消硬编码 REINIT 键表，完全以 schema.group 为准。调试：localStorage.physics-lab-debug-params=1。

1b. 「重跑」vs「恢复安全默认」

控件行为
工具栏「重跑」保持当前参数，从 t=0 重新积分（tooltip 同此）
机箱「恢复安全默认」宽量程 NaN / 发散后：回到模型 schema 默认参数 + 安全全局量

2. 现有参数

工作台内数值可任意输入（含科学计数）。电位器仅参考调节；双击旋钮恢复默认；方向键按量级步进，Home 复位。离散 algo 等为下拉。

3. 自定义键

keyeffect
a_extra / a_*累加到加速度 / 角加速度（质点类模型）
k_extra弹簧 k_eff = k + k_extra
expr_a受限表达式，结果累加到加速度
其它写入 params；模型读取同名键则直接生效

4. expr_a

expr_a = -0.2 * v
expr_a = a_extra + 0.01 * t

仅允许标识符与 + - * / % ( )。无 Math.*。场 / 冲量模型不走 expr_a，见下节。

6. 无 expr_a 时怎么改（collision / wave / heat）

collision · 一维碰撞

冲量瞬时发生，没有连续加速度项；expr_a / a_* 不会接入。直接改：

  • m1, m2 — 质量比决定碰后分配
  • v1, v2 — 初速（符号为方向）
  • e — 恢复系数（0 完全非弹，1 完全弹性）
m1=4  m2=1  v1=2  v2=0  e=0.5

wave · 横波 / 弦

离散弦场，步进是波动方程而非单点 a(t)。改：

  • c — 波速；damp — 阻尼
  • A1… 或模型内振幅 / 初形参数
  • 不要加 expr_a（不会驱动网格节点）
c=1.5  damp=0.02

heat · 热传导

一维扩散场，边界恒温。改：

  • alpha — 热扩散率（过大显式格式会炸）
  • Tleft, Tright, T0, hotspot — 边界与初温
  • N, L — 网格分辨率与长度
alpha=0.01  Tleft=100  Tright=20  hotspot=80
