                  データファイル

                  保存先

                  しくみ

                  記録するたびに、選んだデータファイルへ自動で保存します。ブラウザ内にも予備を保存しています。次回起動時は同じファイルに自動で再接続し、ほかの端末で更新された内容があれば読み込みます。

                  この端末では、ファイルへ自動で保存できません。次の手順でパソコンとデータをやり取りします。

                  1. 使い始めに「データファイルを読み込む」で、OneDrive にあるデータファイル（作業記録データ.txt）を選びます。
                  2. 記録はこの端末の中に保存されます。
                  3. 使い終わったら「共有して保存」を押し、共有先で OneDrive を選んで、同じフォルダに同じ名前で保存します。

                  同じ名前のファイルがすでにある場合、OneDrive が別の名前（「(1)」付きなど）で保存することがあります。その場合は、パソコンでそのファイルを開き直してください。

                  やること・お知らせ

                  お知らせの時刻

                  やることの「お知らせ」で「前日」「当日の朝」を選んだときに、この時刻にお知らせします。

                  端末の通知と音

                  しくみ

                  お知らせは、このツールを開いている間に届きます。パソコンでは別のタブを見ていても届きます。Android でツールを閉じていたり、裏に回していたりすると、届かないことがあります。

                  集計のしかた

                  日報画面の「顧客・案件別の合計」の時間を、日報システムの決まりに合わせます。
