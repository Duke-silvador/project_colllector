НЕ ПРОСТО
ГОНКИ.

SpeedForStreet — это жизнь в большом городе. Ты начинаешь практически с нуля, а дальше сам строишь своё будущее.

Работаешь. Покупаешь первую машину. Получаешь права. Снимаешь жильё. Тюнингуешь автомобиль. Участвуешь в гонках. Или вообще выбираешь другой путь.

02 / AUTOMOTIVE GROUPS

ЗА КАЖДОЙ МАШИНОЙ
СТОИТ МАРКА.

В SpeedForStreet будут собственные автомобильные производители — со своей историей, философией, эмблемой и модельным рядом.

Открывай карточки брендов, изучай их прошлое и знакомься с машинами, которые они создают. Список будет расширяться вместе с миром игры.
