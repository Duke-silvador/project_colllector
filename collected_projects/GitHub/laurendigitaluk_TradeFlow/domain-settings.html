How connection works

One website, one address

  1. Add your domain above.
  2. Point the domain's DNS to the TradeFlow website hosting target provided during the hosting setup.
  3. TradeFlow verifies the domain and marks it active.
  4. When your website is published, the published-site index maps that hostname to your business website automatically.

The DNS/hosting target is intentionally not hard-coded yet because the multi-subscriber hosting layer has not been selected. We should not invent a DNS target and risk sending subscriber domains to the wrong service.
