Crop PDF Pages Online

Cropping can reduce empty margins or distracting scan edges. It changes the visible page area, so inspect footnotes, stamps, signatures, and text near the edges before sharing the result.

Open Crop PDF Tool

Step-by-step instructions

  1. Open PDFLeo and choose Crop PDF.
  2. Select the PDF or supported document from your device.
  3. Use the options shown by the tool and check the selected pages or settings.
  4. Run the operation and download the output if processing completes.
  5. Open the downloaded file and confirm the result before sharing or relying on it.

Tips for a better result

  • Do not crop close to small footnotes.
  • Check mixed-size pages individually.
  • Keep the original because cropping is not secure redaction.
Important: Keep an original copy of important documents. Always review the exported file; results can vary with file structure, quality, and supported features.

Frequently asked questions

Does cropping permanently remove hidden content?

Not necessarily; do not use cropping to hide confidential information.

Can I undo a crop?

Keep the original PDF so you can start again.
