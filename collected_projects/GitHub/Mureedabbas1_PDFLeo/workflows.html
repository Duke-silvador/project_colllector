PDF workflows

A workflow is a repeatable sequence of document tasks, such as merging files and then rotating or extracting pages.

What you can do today

PDFLeo currently lets you run one tool at a time in your browser. For a multi-step task, download the result of the first tool, then choose it as the input to the next tool.

  1. Merge PDF — combine source files.
  2. Organize PDF — set the final page order.
  3. Compress PDF — optionally reduce file size, understanding that pages are rasterized.

Custom saved workflows are not available yet. This page does not claim that automatic chaining, saved presets or team workflows are implemented. Those require a separate workflow builder.
