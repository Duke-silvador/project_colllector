Frequently asked questions

Quick answers about using PDFLeo.

Are PDFLeo tools free?

The current public tools are offered free of charge. No paid subscription is required to use the current tool collection.

Are my files uploaded?

Most available tools process selected files in your browser rather than uploading them to a PDFLeo file-processing server. Your browser may still request third-party libraries, and account or usage analytics requests can be sent to configured services. Read the Privacy Policy for details.

Why did a conversion change my layout?

Some current conversions extract text and rebuild a simplified document instead of preserving the original fonts, charts, images or page layout. Always check the downloaded result.

Does Compress PDF preserve searchable text?

The current browser compression mode renders pages into images to reduce image quality/file size. Text selection, links, forms and vector details may be lost. Check the output size before using it.

Can PDFLeo unlock or password-protect a PDF?

These advanced features are not enabled yet because a specialist engine is required. Do not upload a sensitive document expecting these operations to work.

Does Redact PDF permanently remove private text?

Secure redaction is disabled until a proper redaction engine is available. Drawing a black rectangle over text is not safe redaction.

Can PDFLeo fill interactive forms?

PDFLeo can fill supported existing AcroForm text fields, checkboxes and choice fields. Creating new fields and some specialized form types are not supported, and encrypted PDFs may fail to load.

Can I use PDFLeo on a phone?

The website is responsive and can be opened in a mobile browser. Camera scanning and native mobile apps are not currently provided as full dedicated products.

What if a tool fails?

Try a valid, non-corrupt file, refresh the page and use an up-to-date browser. Keep a backup of the original document.

How do I contact PDFLeo?

Use the contact address listed on the website only once that mailbox has been configured and is being monitored.
