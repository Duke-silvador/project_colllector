Tool availability

Available tools run locally in your browser, but some have limitations. PDF/A conversion uses Ghostscript WebAssembly and still needs separate validation for standards compliance. Password protection/unlocking and secure redaction use rasterized page output and may lose selectable text, links, forms and metadata. Translation sends selectable text to a third-party service and exports text rather than preserving layout. Basic filling of supported existing PDF form fields is available; creating new fields is not. Compression uses image-based rendering and may remove searchable text, links, forms and vector detail. Optimize is a basic re-save, and Repair cannot recover every damaged PDF. Some conversions export text rather than preserve original layout.
