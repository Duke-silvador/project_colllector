How to compress a PDF file

Read the complete PDF compression guide →

PDFs with high-resolution images can be large. Image-based compression can reduce size by rendering each page as a JPEG, but this changes the document: text may no longer be searchable and interactive forms or links can be lost. Compare the output size and readability before sending it.

How to reorder PDF pages

Use Organize PDF and enter every page number once in the desired order. For example, entering 3,1,2 moves the third page to the front. The sequence must include every page exactly once.

Try Organize PDF →

OCR vs. text extraction: what is the difference?

Text extraction reads text already embedded in a PDF. OCR attempts to recognize text in page images, such as a scanned paper document. OCR quality depends on image clarity, rotation, language and the recognition engine. Always proofread extracted text.

How to convert JPG images to PDF

Place images in the order you want them to appear, select JPG to PDF, and create the document. Check page orientation, cropping and image readability before sharing. Very large photos can create a large PDF, so reduce image dimensions first when appropriate.

How to add page numbers to a PDF

Page numbers make long reports and handouts easier to navigate. After applying numbering, inspect the first and last pages and check that the numbers do not cover existing text, footers or signatures.

PDF redaction: why drawing a black box is not enough

True redaction removes the underlying sensitive content from the file. Placing a black rectangle over text can leave the original text recoverable by copying, searching or inspecting the PDF. PDFLeo's Redact PDF feature is disabled until secure content removal is available. Use a trusted, verified redaction tool for confidential material.

Before converting a PDF to Word or Excel

PDFs store pages visually, while Word and Excel use editable document structures. Conversion may lose columns, tables, fonts, spacing or page layout. Review the converted file carefully and compare it with the original before using it in a business or academic workflow.
