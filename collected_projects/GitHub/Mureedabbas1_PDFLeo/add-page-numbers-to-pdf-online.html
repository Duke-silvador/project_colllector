Add Page Numbers to a PDF

Page numbers help readers navigate reports, manuals, and submissions. Before adding numbers, decide whether the cover should be numbered and whether new numbers should match any existing printed pagination.

Open Add Page Numbers Tool

Step-by-step instructions

  1. Open PDFLeo and choose Add Page Numbers.
  2. Select the PDF or supported document from your device.
  3. Use the options shown by the tool and check the selected pages or settings.
  4. Run the operation and download the output if processing completes.
  5. Open the downloaded file and confirm the result before sharing or relying on it.

Tips for a better result

  • Leave enough margin to avoid footers.
  • Decide where numbering begins.
  • Keep the original if it contains a table of contents.
Important: Keep an original copy of important documents. Always review the exported file; results can vary with file structure, quality, and supported features.

Frequently asked questions

Can I skip the cover page?

Use start-page options if available and check the result.

Will a table of contents update automatically?

Usually not; update it separately if needed.
