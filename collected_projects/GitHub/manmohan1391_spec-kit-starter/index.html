Stop vibe coding. Spec it first.

GitHub's Spec Kit makes your AI agent write the rules, the spec, the plan and the tasks before it writes any code. Here's how to set it up with Claude Code and build a small feature in 6 steps.

From the reel by @whats.ai.with.manu

# Install (needs Python 3.11+ and uv)

uv tool install specify-cli

# Create a project for Claude Code

specify init my-project --integration claude
cd my-project && claude

The 6 steps

Run these inside Claude Code, one at a time, and read each file before the next. Open a step for the prompt from the photo-albums example and what you should get.

    Spec is what, plan is how

    "Group photos by date" belongs in the spec. "Use plain JavaScript on Node" belongs in the plan. Keep them apart and both stay useful.

    Hyphen, not dot

    In Claude Code the commands are /speckit-specify and so on. Type /speckit and pick from the menu.
