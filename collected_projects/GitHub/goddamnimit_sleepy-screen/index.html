sleepy screen

A calm, text-only home screen. Sleepy Screen turns your home screen into a quiet launcher built from widgets, with a different setup for each Focus.

Support

Questions, bugs or ideas: please open an issue. I read every one.

Getting started

  1. Open the app and create a Space (a list of launcher items with its own look).
  2. Long-press your home screen, tap +, search for the app and add the Launcher and Top widgets.
  3. Long-press a widget → Edit Widget to choose which Space it shows.
  4. Open Setup guide inside the app for hiding extra pages, matching your wallpaper and linking Spaces to Focus modes.

Common questions

Tapping an item doesn't open the app. iOS asks permission the first time a widget opens another app; tap Open. Check Settings → Diagnostics in the app to see what happened. Some apps have no URL scheme: use a Shortcut item instead.

Widgets look different from my wallpaper. Use Theme → Match my home screen, retake the screenshot after any wallpaper change, and nudge by a pixel or two. Use the Default (not Clear or Tinted) home screen appearance.

Why is the name under my widgets blank? It is deliberate: the app's home-screen name is an invisible character so widgets look clean. Find the app by its icon.
