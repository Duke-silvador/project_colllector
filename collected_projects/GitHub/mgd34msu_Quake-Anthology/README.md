# Project: mgd34msu/Quake-Anthology

**Source:** GitHub

**Description:** C port of the Quake-Anthology-TS engine, which is itself based on the Quake 1, Quake 1 Rerelease, Quake 2, Quake 2 Rerelease, and Quake 3 source code. It's come full circle: C -> TS -> C. My Quake Anthology TS engine eventually ran into issues with getting game ticks to happen fast enough. This port should be able to solve the issue.
