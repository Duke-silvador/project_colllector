Live tracking without surrendering the map scale

The tracker uses ArcGIS Earth's documented local Automation API. On each valid RMC update it reads the current camera, changes only X/Y to the current ME position, and preserves camera height and orientation. In live testing, the map recenters while the selected zoom stays put.

Live-tested ME center-screen tracking on ArcGIS Earth desktop.

Operator control: press T in the tracker console to toggle ME tracking. Stop the tracker process to suspend all live drawing updates.

Mobile offline deployment

Esri documents TPK/TPKX as supported local files in ArcGIS Earth Mobile. This project has additionally exercised a large local archive across several Android-class devices.

Phone & tablet

District imagery can live locally instead of depending on a cellular data path at incident time.

Removable media

Project testing successfully opened TPKX from microSD and exFAT USB on an Android phone.

Picker caveat

On some Android paths, the in-app removable-storage picker can misbehave even when the same file opens from Android's file manager.

Downloads & manuals

The ZIPs below are cleaned distributions from the supplied working packages. Test-era names/cache files were removed where they were not required for operation.

What you need: ArcGIS Earth (free) for the maps and the tracker · ArcGIS Pro 3.7 (licensed, 21-day free trial) and the .NET 10 SDK (free) for the Batch Factory · Python 3 (free) for the tracker and tester (their launchers install the pyserial add-on automatically the first time).

First time? 1) Right-click the downloaded zip > Extract All, then open the new folder. 2) If Windows warns about a downloaded program, click More info > Run anyway (or Run); to avoid it, right-click the zip > Properties > tick Unblock before extracting. 3) When installing Python, tick "Add python.exe to PATH" if the installer shows it.

Important boundaries

The repository distributes tools and documentation, not an imagery archive. Production computers need authorized access to the map source while building packages. Once produced and copied to field hardware, the TPKX files are local/offline content.
