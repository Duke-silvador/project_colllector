Experience Mode

You've just joined the BI team at Northwind Outdoors, a mid-sized outdoor gear retailer. Requests arrive as tickets, emails and chat messages. They are incomplete, sometimes contradictory, and occasionally urgent. Nobody tells you which feature to use: you get the evidence and you decide.

Request→Ambiguity→Discovery→Investigation→Design→Build→Test→UAT→Deploy→Monitor→Incident→Postmortem→Improve

Each scenario has a brief, real files to work with, progressive hints, a professional rubric and a model answer that opens when you ask. Scenarios build on each other: the dashboard you build in Sprint 01 is the one Finance disputes in Sprint 02. Most need only Power BI Desktop (free). Where a Fabric or Service feature would need a licence, the evidence includes the logs and screenshots-as-data you would have seen.
