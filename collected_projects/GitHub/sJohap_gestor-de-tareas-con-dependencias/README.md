# Project: sJohap/gestor-de-tareas-con-dependencias

**Source:** GitHub

**Description:** gestor de tareas con dependencias. Permite registrar tareas y definir de cuáles dependen. Una tarea solo puede empezar cuando ya terminaron todas las previas. Modela esas relaciones como un grafo dirigido para detectar ciclos, calcular un orden válido de ejecución y consultar cuáles están listas, bloqueadas o completadas. Proyecto final del tema 1
