Icône couleur

Cette page est destinée à installer une nouvelle icône pour la version 2.4.1.

  1. Ouvre cette page dans Safari sur ton iPhone.
  2. Appuie sur Partager, puis Sur l’écran d’accueil.
  3. Vérifie que l’image en couleur apparaît dans l’aperçu, avant d’appuyer sur Ajouter.

Si l’aperçu affiche encore « É », n’ajoute pas l’icône.
