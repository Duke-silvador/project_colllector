♟ 100 défis de paix originaux

Inspirés du principe du livret Chess Peace : placer 7 pièces sur 5 × 5 cases sans qu'une pièce blanche puisse attaquer une noire, ni l'inverse.

Ces défis numériques sont nouveaux : ils ne reproduisent ni les 60 défis ni les supports de puzzle du fabricant. Plusieurs solutions peuvent être acceptées.

Choisis une pièce, puis touche une case libre. Touche une pièce posée pour la retirer.

En 3D : glisse pour tourner, pince pour zoomer, touche une case pour poser une pièce. La vue 2D reste disponible.

Comment jouer ?

Les pièces marquées 🔒 sont imposées. Place toutes les autres sur des cases vides. Les attaques suivent les règles des échecs : le cavalier saute, tandis que la tour, le fou et la dame sont bloqués par la première pièce rencontrée. Les pièces de même couleur peuvent s'attaquer ; seules les attaques entre couleurs opposées sont interdites.

Différence avec le jeu physique : ici les pièces sont placées individuellement et non sur des supports polyominos. Le défi consiste à obtenir une position paisible, pas à reconstituer le puzzle matériel.

Les 100 défis et une position valide pour chacun sont inclus dans le programme, accessibles hors ligne. La progression est enregistrée sur cet appareil.
