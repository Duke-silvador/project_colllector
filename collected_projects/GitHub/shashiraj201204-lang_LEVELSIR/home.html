// FAQ

Common questions

Quick answers about how XIRUS MODZ works.

What is XIRUS MODZ?

A free control panel where you add your IDs, watch live logs, switch modes and track stats in one place.

How do I get started?

Tap Get Started, create a free login, then add your IDs inside the dashboard.

Is it really free?

Yes. There are no payments, no trial timer and no upgrade screens.

How many IDs can I add?

Each user can run up to 5 IDs. Add them one by one or import them from a JSON file.

Can I pause or restart an account?

Yes. Every account can be paused, refreshed or restarted anytime from the dashboard.

What can I monitor?

Live activity logs plus online status, in match, EXP, matches and uptime on the stats cards.
