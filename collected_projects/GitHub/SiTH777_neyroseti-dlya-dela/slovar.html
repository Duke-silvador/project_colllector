Каталог / Словарь

Словарь нейросетей простыми словами

Термины, которые встречаются в описаниях сервисов, — без академических формулировок.

Промпт

Текст запроса к нейросети: что нужно сделать и в каком виде.

Токен

Единица текста, которой считает модель: примерно 3–4 символа русского текста.

Контекстное окно

Сколько текста модель может держать в одном запросе.

RAG

Поиск по своим документам перед ответом модели.

Fine-tuning

Дообучение модели на своих примерах под узкую задачу.

Галлюцинация

Уверенный, но неверный ответ модели.

API

Программный доступ к модели: запросы из кода, а не через чат.

Эмбеддинги

Числовое представление смысла текста для поиска похожего.

AI-агент

Модель, которая сама делает несколько шагов: ищет, вызывает инструменты, проверяет.

Мультимодальность

Модель понимает не только текст, но и картинки, аудио, видео.

LLM (большая языковая модель)

Модель, обученная предсказывать следующий фрагмент текста на огромном корпусе. На этом построены ChatGPT, Claude, GigaChat.

Температура

Параметр, управляющий случайностью ответа: низкая — предсказуемо, высокая — разнообразно.

Системный промпт

Инструкция, которая задаёт модели роль и правила до начала диалога.

Few-shot (обучение на примерах)

Способ задать формат ответа, показав модели 2–5 готовых примеров прямо в промпте.

Chain of Thought (цепочка рассуждений)

Просьба к модели рассуждать по шагам перед ответом.

Векторная база

Хранилище, которое ищет не по словам, а по смыслу: тексты сравниваются как векторы.

OCR (распознавание текста)

Превращение картинки или скана в текст, с которым можно работать.

ASR (распознавание речи)

Перевод аудио в текст: расшифровка созвонов, интервью, диктофонных записей.

TTS (синтез речи)

Обратная задача: текст превращается в озвучку.

Prompt injection

Атака, при которой в документ или на сайт прячут инструкцию, и модель выполняет её вместо вашей.
