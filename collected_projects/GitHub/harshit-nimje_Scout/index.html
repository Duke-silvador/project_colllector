Connect TMDB

  1. Make a free TMDB account

    Sign up at themoviedb.org, then open Settings → API. It’s free for non-commercial use.

    Open TMDB settings
  2. Copy the key

    Under API Key (v3 auth) copy the long string. A v4 read access token also works.

  3. Paste it here
  4. What it unlocks

    Posters, cast, trailers and the full film & TV catalogue. Without it, cine runs on an offline editorial set of curated titles.

This product uses the TMDB API but is not endorsed or certified by TMDB. Your key and your taste stay on this device.
