半品齐套管理看板 — 操作手册

组装部培训用 · 版本 2026.09.05

系统概述

半品齐套管理看板用于管理半成品的入库、出库和齐套分析。通过扫描产线上的二维码标签，系统自动记录每次扫码操作，实时计算库存，并在看板上展示每个成品料号的齐套状态。

核心功能：

  • BOM导入 — 加载成品与半品的对应关系
  • 工单管理 — 设置当前生产的工单号及数量
  • 扫码录入 — 扫码枪或手机相机扫描半成品标签
  • 库存计算 — 自动统计各半品当前库存
  • 齐套看板 — 实时显示每个成品的齐套情况
  • 数据导出 — 导出CSV/Excel台账

二维码标签格式

每根半成品的标签上有一个二维码，扫码后得到的内容格式如下：

工单号｜半品料号｜线长｜数量(包规)｜批次｜流水号

实际示例：

101396002｜8180900969-P1A1-P2B2｜00035｜00100｜260905｜00001
段落字段名称说明示例
第1段工单号当前生产工单编号101396002
第2段半品料号该半成品的料号（含线序信息）8180900969-P1A1-P2B2
第3段线长线材长度（系统暂不使用）00035
第4段数量（包规）每箱装多少根，不计入库存00100
第5段批次生产日期，6位日期 YYMMDD260905
第6段流水号序号（系统暂不使用）00001
⚠️ 分隔符说明 各段之间用竖线分隔（支持全角 ｜ 和半角 |），系统会自动识别。

业务规则

📌 库存计数规则

  • 一根线 = 一个码 = 扫一次 = 库存+1
  • 标签上的"数量"是包规（每箱装多少根），不记入库存
  • 入库扫一次 → 库存+1；出库扫一次 → 库存-1

📌 工单与成品关系

  • 一个工单号可以对应多个成品料号
  • 扫码时，系统会自动在BOM中查找该半品料号属于哪个成品
  • 只要半品料号在当前工单关联的任何一个成品的BOM中，就允许录入

📌 齐套判定

  • 一个成品需要多种半品，每种半品的库存都 ≥ 需求量时，才算"可配套"
  • 最大缺口 = 该成品下库存最多的半品数量 − 库存最少的半品数量
  • 可配套数 = 所有半品中能配套的最小套数（受限于库存最少的那种半品）

1 导入BOM数据

BOM（物料清单）定义了每个成品需要哪些半品，是齐套分析的基础数据。

1
打开系统页面，找到顶部 "📂 BOM 数据管理" 区域
2
点击 "📋 批量录入" 按钮，选择BOM文件（Excel 或 CSV 格式）
3
系统自动解析文件，解析成功后会显示已加载的成品和半品数量
💡 BOM文件格式要求 文件中需包含：成品料号、半品料号、接头规格等字段。系统会自动匹配列名识别。

2 设置工单

扫码前需要先确认当前生产的工单号和工单数量。

1
在 "📋 工单设置" 区域，输入工单号和工单数量
2
点击 "✅ 确认" 按钮
3
确认成功后，工单信息会自动同步到后续的扫码记录中
字段说明示例
工单号当前生产工单编号101396002
工单数量本工单计划生产的成品数量500
✅ 提示 一个工单可以对应多个成品料号。设置工单后，扫描该工单下任何成品的半品都会被接受。

3 设置栈板号

栈板号用于标识扫码时半成品所在的栈板位置，方便后续追溯。

1
在扫码区域找到 "🏷️ 栈板号" 设置
2
选择栈板前缀（下拉框），可选值：5B3F、2B3F、2B4F
3
输入序号（如 1、2、3...），系统自动拼接为完整栈板号

栈板号格式示例：

前缀序号完整栈板号
5B3F15B3F-0001
2B3F152B3F-0015
2B4F32B4F-0003
💡 自动保存 栈板号设置会自动保存，刷新页面后不会丢失，无需重复设置。

4 扫码操作

这是日常使用最核心的操作：扫描半成品标签上的二维码完成入库或出库。

扫码方式

方式适用场景操作
扫码枪电脑端，批量扫码光标定位到扫码框，直接扫码即可
📷 相机扫码手机端，或无扫码枪时点击扫码框右侧的 📷 按钮，调用摄像头

入库操作

1
确认已选择 "📥 入库" 模式（默认即为入库）
2
将扫码枪对准标签二维码扫描（或点击📷用手机相机扫码）
3
扫码成功后，系统自动识别半品料号，该半品库存 +1
4
扫码记录立即出现在下方 "📋 扫码记录" 列表中

出库操作

1
点击切换到 "📤 出库" 模式
2
扫描标签二维码
3
扫码成功后，该半品库存 -1

齐套看板

看板指标说明

列名说明

半品数该成品需要的半品种类数
可配套数当前库存能配套的最大套数（受限于最缺的半品）

缺料半品库存不足需求量的半品种类数

数据导出

CSV 导出

点击 "💾 导出 CSV" 按钮，系统会将所有扫码记录导出为 CSV 文件。

CSV 包含以下 10 列：

列序列名数据来源
1时间扫码时间（精确到秒）
2唯一码完整扫码内容（6段拼接）
3线序料号二维码第2段（半品料号）
4操作人暂空（预留）
5工单号当前确认的工单号
6工单数量当前确认的工单数量
7库位二维码第1段（扫码内容中的工单号）
8批次二维码第5段（6位日期，如260905）
9动作入库 / 出库
10栈板号当前设置的栈板号（如5B3F-0001）
💡 提示 CSV 文件可用 Excel 或 WPS 打开。如打开后中文乱码，请在 Excel 中使用"数据 → 从文本/CSV"导入，选择 UTF-8 编码。

Excel 多Sheet导出

系统还支持导出包含多个 Sheet 的 Excel 文件，包括 BOM 数据、工单信息、齐套看板和扫码区等。

点击 "📊 导出 Excel" 按钮即可下载。

常见问题

Q1：扫码后提示"不在当前工单BOM中"怎么办？

A：请检查以下几点：

  • 确认当前设置的工单号是否正确
  • 确认该半品料号确实属于当前工单关联的成品BOM
  • 如果BOM尚未导入，请先导入BOM数据

Q2：为什么扫同一个码会提示"重复扫码"？

A：系统会自动检测重复扫码。同一个码在同一方向（入库或出库）只能扫一次。如果需要同一半品增加库存，应该扫不同流水号的标签。

Q3：标签上的数量（包规）为什么没有计入库存？

A：这是设计规则。标签上的数量表示每箱装多少根（包规），不是库存数。每扫一次码 = 一根线 = 库存+1。包规只作为参考信息记录，不参与库存计算。

Q4：一个工单可以扫多种不同成品的半品吗？

A：可以。一个工单号可以对应多个成品料号，扫描这些成品下任意半品都会被接受。系统会自动在BOM中查找匹配关系。

Q5：刷新页面后数据会丢失吗？

A：不会。扫码记录保存在云端，刷新页面后会自动恢复。栈板号设置也保存在本地，刷新不会丢失。

Q6：多人同时扫码会冲突吗？

A：不会。多人可以在各自的设备上同时打开系统扫码，数据通过云端实时同步。每台设备的库存也会自动从初始值 + 所有扫码记录重新计算，确保数据一致。

Q7：批次信息（如260905）代表什么？

A：批次是二维码标签第5段的6位日期数字，格式为 YYMMDD。例如 260905 表示 2026年9月5日生产。批次信息会记录到扫码记录和导出的CSV中，方便追溯。

Q8：导出的CSV文件用Excel打开中文乱码怎么办？

A：CSV 文件使用 UTF-8 编码。在 Excel 中请通过以下方式打开：

  1. 打开 Excel → 点击"数据"选项卡
  2. 选择"从文本/CSV"
  3. 选择导出的文件
  4. 在编码选择中选 UTF-8
  5. 点击"加载"
