Сканер читов для Garry's Mod · UnionTeams
СКАЧАТЬ GMOD SCAN
GModScan.exe · Windows 10/11 · Проверка аккаунтов Steam
⚠ ПОЧЕМУ АНТИВИРУС РУГАЕТСЯ НА ПРОГРАММУ?
  • Читает системные папки (Prefetch, AppData) — сканер проверяет системные директории Windows для поиска следов читов. Именно такое поведение антивирусы считают подозрительным, хотя это стандартный метод анализа.
  • Обращается к реестру Windows — поиск следов установленных программ идёт через реестр. То же самое делают CCleaner, Process Monitor и другие системные утилиты.
  • Ищет файлы по всему диску — глубокое сканирование требует прав доступа к охраняемым папкам, поэтому может потребоваться запуск от администратора.
  • Читает процессы других программ — для обнаружения запущенных чит-процессов получается список всех активных процессов. Эвристика антивирусов реагирует на это.
  • Нет коммерческой подписи (EV-сертификат) — сертификат стоит денег. Scanner — бесплатный проект без подписи, поэтому SmartScreen показывает предупреждение.
✓ Исходный код открыт — любой может проверить что делает программа.
Если Windows покажет предупреждение SmartScreen, проверьте издателя и цифровую подпись программы перед запуском.
