🔒 Приватность и безопасность

Анализ файлов выполняется исключительно на стороне клиента (в браузере). Конфиденциальные данные не покидают ваш компьютер.

1. Предмет соглашения

Steam Checker — бесплатный инструмент для локального анализа данных Steam. Администрация обеспечивает корректную работу алгоритмов извлечения SteamID из файлов: userdata, avatarcache, config.vdf.

2. Безопасность и защита данных

Обработка данных изолирована в браузере. Никакие файлы, куки, токены или идентификаторы не передаются на внешние серверы и не сохраняются в базах данных. Авторизация через Steam OpenID происходит через официальный сервис Valve.

3. Легальное использование

Используя данный инструмент, вы подтверждаете, что анализируете только собственные файлы или файлы, к которым имеете законный доступ. Запрещается использование сервиса для фишинга, взлома аккаунтов или иных действий, нарушающих правила Steam (Valve Corporation).

4. Функция администраторов

Авторизованные администраторы проекта UnionTeams имеют доступ к расширенным функциям (автоформа команд). Данные об администраторах получаются из публичного API UnionTeams и не сохраняются постоянно.

5. Отказ от ответственности

Сервис предоставляется по принципу «как есть». Администрация не несёт ответственности за программные ошибки, блокировки аккаунтов со стороны Valve или косвенные убытки при использовании инструмента.

6. Изменения условий

Условия могут быть пересмотрены в любое время. Продолжение использования сайта означает согласие с обновлённой версией.
