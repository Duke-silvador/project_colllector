# Project: yashthakare-07/Boiler-DCS-Control-System

**Source:** GitHub

**Description:** Industrial process-control digital twin for a boiler and steam utility plant, integrating OpenPLC, Python-based process simulation, Modbus TCP, FUXA SCADA/HMI, cascade pressure control, three-element drum-level control, simulated protective interlocks, and closed-loop performance validation.
