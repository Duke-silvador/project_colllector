PrivatFinanz

Datenschutzhinweise

Status: PrivatFinanz ist eine nicht öffentlich angebotene App für den persönlichen Eigengebrauch und befindet sich in Entwicklung. Die folgenden Angaben beschreiben die geplante Nutzung und werden vor dem produktiven Einsatz überprüft und bei Bedarf aktualisiert.

1. Zweck der Anwendung

PrivatFinanz dient der persönlichen Übersicht über eigene Bankkonten, Kontostände, Umsätze und daraus abgeleitete Finanzstatistiken. Die Anwendung wird nicht als Dienstleistung für Dritte angeboten.

2. Bankverbindung über Enable Banking

Für den Zugriff auf Bankkontoinformationen ist eine Anbindung an Enable Banking vorgesehen. Der Kontozugriff erfolgt nur nach einer entsprechenden Autorisierung durch den Kontoinhaber und im Umfang der erteilten Berechtigung. Es sollen ausschließlich eigene, ausdrücklich verknüpfte Konten abgerufen werden.

3. Welche Daten verarbeitet werden sollen

Vorgesehen sind Kontobezeichnungen und -kennungen, Kontostände, Buchungsdaten, Beträge, Buchungstexte sowie gegebenenfalls Empfänger- oder Absenderangaben. Diese Informationen dienen ausschließlich der privaten Finanzübersicht.

4. Speicherung und Weitergabe

Geplant ist eine lokale Speicherung der abgerufenen Finanzdaten auf dem eigenen Gerät. Es ist keine Veröffentlichung von Bankdaten oder Weitergabe an andere App-Nutzer vorgesehen. Die technische Umsetzung der Synchronisierung und der Schlüsselverwaltung wird noch festgelegt; sollte dafür eine zusätzliche Serverkomponente eingesetzt werden, wird dieser Hinweis entsprechend angepasst.

5. Widerruf und Löschung

Bankfreigaben können über die jeweiligen Bankverfahren beziehungsweise die Verwaltung der Enable-Banking-Freigaben überprüft und beendet werden. Für die App ist eine Möglichkeit zum Entfernen lokal gespeicherter Finanzdaten vorgesehen.

6. Diese Informationsseite

Diese Seite wird über GitHub Pages bereitgestellt. Beim Aufruf kann GitHub technische Zugriffsdaten nach seinen eigenen Datenschutzbestimmungen verarbeiten. Diese Website verwendet selbst keine Tracking-Skripte, keine Analysewerkzeuge und keine Cookies, die durch den Seiteninhalt gesetzt werden. Sie empfängt und speichert keine Bankdaten.

7. Kontakt

Für Fragen zum Datenschutz kann die bei Enable Banking für PrivatFinanz hinterlegte Datenschutz-Kontaktadresse verwendet werden.
