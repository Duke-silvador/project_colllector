**Source:** GitHub

**Description:** Interaktywny, 3-stronicowy raport Power BI dla europejskiego e-commerce w branży rowerowej (Sprzedaż, Produkt, Klient). Projekt obejmuje: proces ETL w Power Query,  kod DAX oraz projekt UI/UX layoutu w programie Figmie.
