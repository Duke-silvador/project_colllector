Privacy

Last updated: October 24, 2026

Panda Client is in development. This page describes how the launcher handles your data. If anything changes, we update this page first.

Your Microsoft account

  • You sign in on Microsoft's own sign-in page. Panda Client never sees or stores your password.
  • The launcher stores only the Microsoft refresh token, so you don't have to sign in every time. It is encrypted with your operating system's keychain.
  • The Minecraft token and your profile (name and UUID) are kept in memory only while the launcher runs.
  • Tokens never appear in any log, not even in the command line that starts the game.

Who the launcher talks to

Microsoft
Sign-in with your Microsoft account
Xbox Live
Sign-in tokens for Minecraft
Mojang
Minecraft token, ownership check, your profile, game files and the Java runtime
FabricMC
The Fabric Loader that runs our client mod

Their own privacy policies apply, for example the Microsoft Privacy Statement.

What we don't do

  • We don't run any servers of our own right now. If we add one (for example for updates), we update this page first.
  • No analytics, no telemetry, no ads.
  • We don't sell or share any data with third parties.

This website

This website is hosted on GitHub Pages. It uses no cookies, no analytics and no external scripts. GitHub processes technical data such as IP addresses to deliver the site, see the GitHub General Privacy Statement.

Contact

Questions about Panda Client or this page: open an issue at github.com/Panda-Client/panda-client.github.io.
