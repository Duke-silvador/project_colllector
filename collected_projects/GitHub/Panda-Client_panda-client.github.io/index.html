Panda Client

A custom launcher and client for Minecraft: Java Edition, built from scratch by three hobby developers.

In development · not released yet

Why we build it

We are three hobby developers who enjoy programming and designing interfaces. Instead of using a prebuilt launcher, we are building our own from scratch, with a fully custom design and features made the way we like them. Panda Client is a hobby and learning project for us.

What it is

Launcher

A desktop app that gets the game ready and starts it.

  • Sign-in with your Microsoft account
  • Minecraft versions from Mojang's official version list
  • Game files and the Java runtime downloaded from Mojang
  • Installs the Fabric Loader and our client mod

Client mod

Our own Fabric mod that runs inside the game.

  • A custom in-game interface
  • Starts with the newest Minecraft version, older ones follow
  • Which features it gets is still being decided

How sign-in works

  1. Microsoft sign-in. The launcher shows a short code. You enter it on Microsoft's own page at microsoft.com/link, so Panda Client never sees your password.
  2. Xbox Live. The Microsoft token is exchanged for Xbox Live tokens.
  3. Minecraft services. The Xbox Live token is exchanged for a Minecraft token.
  4. Ownership check. The launcher checks that your account owns Minecraft: Java Edition and loads your profile (name and UUID).
  5. Game start. Only then does the game start, signed in as you.

No offline mode. There is no way to skip the sign-in or the ownership check. Panda Client only uses its own Microsoft application ID.

Game files

Panda Client downloads the official game files (the game itself, libraries, assets and the Java runtime) directly from Mojang's servers when you play. We never put Minecraft files into our code, never redistribute them and never ship modified copies. You need your own Minecraft: Java Edition account.

Privacy in short

  • Your password never reaches Panda Client.
  • Only the Microsoft refresh token is stored, encrypted by your operating system's keychain.
  • No analytics, no telemetry, no ads.
  • No data is shared with third parties.
