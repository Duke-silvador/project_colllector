# Project: RaphaelAndradeM3/resonance-player

**Source:** GitHub

**Description:** Resonance é um player de música moderno e local-first para Windows, desenvolvido em C# e WinUI 3, focado em grandes bibliotecas musicais, enriquecimento de metadados, letras, reconhecimento por fingerprint, equalização e visualização de espectro em tempo real. Resonance is a modern, local-first music player for Windows built with C# and WinUI 3.
