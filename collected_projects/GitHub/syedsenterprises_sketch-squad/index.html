📖 How to play (10 seconds)
  1. One player draws a secret word. Everyone else guesses.
  2. Guess right fast = more points. The drawer earns points too.
  3. Everyone draws once. Most points at the end wins!

The host starts the game. Each turn lasts 60 seconds. Wrong guesses show in chat — right guesses stay secret until the reveal.
