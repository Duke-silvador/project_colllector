# Project: DianaMLlamocaZ/IMAGE-CAPTIONING-ANALYSIS

**Source:** GitHub

**Description:** En este repositorio, implementé un modelo de Image Captioning utilizando PyTorch, para evaluar y comparar dos enfoques en la generación de captions: la modificación de hiperparámetros y el análisis del efecto de la frecuencia de palabras con Class Weights. Utilicé estrategias de decoding como Greedy Approach y Beam Search, evaluadas con BLEU Score.
