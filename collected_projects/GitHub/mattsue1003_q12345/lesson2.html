Napkin 是什麼

把一段文字貼進去，它會自動畫成流程圖、步驟圖、比較表、心智圖等視覺圖，可以換風格、改字、加圖示，再匯出成圖片放進單張或簡報。不用會設計、不用會畫圖。

免費版

  • 每週 500 點數，一般衛教用途夠用
  • 可匯出 PNG、PDF，或直接複製到剪貼簿
  • 匯出的圖會有小小的 Napkin 浮水印

六步驟（跟著影片做）

  1. 註冊：用 Google 帳號登入 napkin.ai
  2. 貼上文字：新增文件，把衛教重點貼進去（有個案內容先過去識別化工作台）
  3. 產生圖：反白段落，按藍色閃電，挑一張喜歡的
  4. 換風格：點圖，右側直排工具列的調色盤換配色、其他按鈕換版型或字型
  5. 編輯：增減項目、改字、換圖示
  6. 匯出：PNG 放單張、PDF 列印、複製圖片貼到簡報，這三種免費，但圖上會有 Napkin 小標記。要能在 PowerPoint 裡改字的 PPT 檔、SVG 向量檔，或拿掉標記，需付費 Plus 方案（每月 9 美元）。匯出視窗裡也有 Google Slides，是否免費以畫面為準。

先用 AI 整理文字，再丟給 Napkin

Napkin 畫得好不好，取決於你貼的文字有沒有結構。先請 ChatGPT／Claude／Gemini 整理成條列，再貼過去。

三個提醒

① 個資

貼進去的文字一樣會上雲端。

不能貼：

  • 姓名、病歷號、身分證字號、健保卡號
  • 生日、電話、地址、LINE ID
  • 檢驗報告或病歷截圖（表頭常有個資）
  • 病人或家屬照片
  • 「年齡＋罕見狀況＋地點」這類一看就知道是誰的組合
  • 院內未公開的數據、公文、同事評語

可以貼：已公開的衛教單張、自己寫的草稿、合成或已去識別化的資料。

② 隱私設定（註冊後先做）

  1. 右上角頭像 → Account Settings
  2. 切到 Profile 分頁，往下捲到 Data Privacy
  3. Use my content for product improvements（用我的內容改善產品）切到 Off

預設是開的，內容會匿名拿去改善 AI。關了只影響之後的內容；簡報版 Slides 也一起適用。團隊空間由管理員設定。

③ 核對

數據圖它也能畫，但數字、順序要自己對過原文，圖越漂亮越容易被相信。

工具：長照資料去識別化工作台（講師自製，純本機、不連網、不用 AI）

開啟去識別化工作台

它做什麼

上傳 Word、Excel、CSV、PDF、掃描檔或照片、.txt，或直接貼文字，它用顏色標出姓名、稱謂、身分證、電話、Email、病歷號、健保卡號、生日、日期、地址、醫院與機構名稱；你逐一確認後下載去識別化版本。

怎麼替換

姓名 → 個案A、家屬B、人員C（同一人全文一致，可改成「A 阿嬤」這種自訂稱呼）；生日 → 年齡層；日期 → 第 N 天；地址只留縣市＋鄉鎮區；證號、電話、Email 整段遮蔽。

為什麼敢用

全部在你的瀏覽器裡計算，檔案不會離開電腦，工具本身也不呼叫任何 AI 模型。這就是「給 AI 之前的那一道門」，門本身不能再是 AI。

ChatGPT桌面版彩蛋：「Mini 與寵物」到底有什麼用？

一句話：它是一個浮在桌面上的 ChatGPT 快捷鍵。不用切回 ChatGPT 視窗，在 Word、病歷系統、PDF 前面按一下就能打字或用說的問，還能看長任務做到哪。寵物只是外觀，換哪一隻都不影響 AI 的能力。

① 隨叫隨問

Mac 按 ⌥ Option＋空白鍵、Windows 按 Windows＋Alt＋P，叫出浮動小工具。點鉛筆打字、點聲波圖示用說的。和第 1 堂 Gemini 桌面版的快捷鍵同一個概念。

② 看長任務進度

交辦 Work 或深入研究這類要跑 10 分鐘的工作後，可以去做別的事。寵物旁的泡泡會顯示：執行中、需要你回覆、已完成、卡住。鈴鐺圖示可看所有進度。

③ 選 Mini＝只要工具不要寵物

覺得卡通角色不夠專業，就選「無／Mini」，只留下鉛筆、聲波、下拉三個按鈕，一樣能隨叫隨問。

先把一個字釐清：「Bot」這個字有兩種意思。舊的意思是「聊天機器人」，也就是任一家的對話模式，背後就是 LLM，一問一答。但 2026 年 8 月 xAI 推出的 Grok Bot 不是聊天機器人，它是常駐在雲端、有自己一台電腦、24 小時不關機的 AI Agent：你像傳訊息給同事一樣交辦，它自己登入網站、跑流程、照排程重複做。下面這張圖裡的「對話」是舊意思，「Grok Bot」是新意思，請不要混在一起。

常見混淆，一句話回答

  • 「Agent 跟聊天機器人差在哪？」聊天機器人（LLM 對話）回答你，Agent 替你做。判斷方法：它會不會自己跑第二步、第三步而不用你再按一次。
  • 「Grok 跟 Grok Bot 差在哪？」Grok 是 xAI 的模型和聊天 App（X 上的 @grok、grok.com），一問一答，屬於上面的「對話」。Grok Bot 是 Agent，而且是常駐型：有自己的雲端電腦、永遠在線、會排程重複做、幾個 Bot 能互相接力。所以「Bot」這個字在 Grok Bot 裡指的是「數位同事」，不是「聊天機器人」。它和 ChatGPT 工作、Claude Cowork 同一層，差別在「做完就停」和「一直待命」。
  • 「雲端代理可以碰我電腦嗎？」預設不行。要碰，得在電腦上裝本機代理並配對（Claude Code 的 Remote Control、Codex 的雲端⇄桌面），而且每次改動都會回頭問你。
  • 「手機就能跑 Agent？」手機上的 ChatGPT／Claude／Gemini App 跑的是雲端代理；要動到電腦裡的檔案，手機只是遙控器，電腦要開著、本機代理要先啟動。
  • 「Remote Control 安全嗎？」連線經過廠商雲端加密中繼，但等於把電腦交給遠端的你；手機遺失要能立刻登出；只在個人電腦與練習資料夾用，院內電腦依資安規定。

這張圖的三個重點（也是三條規矩）

  1. 人在最上面：決定目標、審核結果、簽名的永遠是人。代理可以「做」，不能「決定」。
  2. 每一條線都是授權：雲端代理要你授權才能碰雲端硬碟；本機代理要你指定資料夾；手機要先配對。沒有一條線是預設打開的。
  3. 重要操作由人確認：刪檔、寄信、送出表單、改病歷相關文件，在任何一層都要停下來問你。外掛權限選「允許唯讀工具」、代理先跑「只讀不改」就是這個意思。
講師怎麼用：白天在門診用手機 Remote Control 交辦家裡電腦上的 OpenCode／Claude Code「把今天的 30 份單張轉成 .md 並列出個資疑慮」；電腦整天開著，晚上回家直接在電腦上審核。手機只負責下指令和看回報，所有檔案都留在電腦裡。

手機遙控電腦上的代理，實際怎麼設：Claude Code Remote Control 與 Codex「連線」

兩家的做法一樣：電腦上先開一個「等人遙控」的工作階段，手機 App 再連進去。手機只是遙控器，所有檔案和執行都留在電腦上；電腦關機或程式關掉，手機就什麼都做不了。下面是 2026 年 11 月的步驟。

Claude Code Remote Control

條件：Pro／Max／Ultra／Team／Enterprise 方案；電腦上裝好 Claude Code（終端機版或 Claude 桌面版的 Code 分頁）並用 claude.ai 帳號登入；手機裝 Claude App（iOS／Android）或用瀏覽器開 claude.ai/code。

  1. 電腦端（三選一）
    ・終端機、進到練習資料夾後打 claude remote-control：第一次會問「Enable Remote Control? (y/n)」，按 y。畫面會給一個網址，按空白鍵顯示 QR code。這個模式是純伺服器，電腦上不打字。
    ・想一邊在電腦打、一邊手機也能接手：claude --remote-control（或 --rc）。
    ・已經在 Claude 桌面版 Code 分頁或終端機對話中：輸入 /remote-control（或 /rc），第一次會跳對話框，選「Enable Remote Control」。
  2. 手機端：Claude App → 底部「Code」→ 工作階段清單會出現電腦那個 session（名稱像「電腦名-xxx」，可用 --name "衛教單張" 自己取）；或直接用手機相機掃剛才的 QR code。
  3. 開始用：手機打字、拍照、傳檔案都行；AI 要動檔案時的「允許／拒絕」也在手機上按。電腦和手機同步顯示同一段對話。
  4. 結束：在電腦終端機按 Ctrl+C，或再打一次 /remote-control 斷開。手機上的紀錄會留在 claude.ai/code。
  5. 想每次自動開：Claude 桌面版「設定 → Code」勾「Connect new sessions to Remote Control」；終端機版在 /config 裡開 Remote Control at startup。
講師提醒：電腦睡著或斷網，它會在恢復後自動重連，但睡著期間任務是停的；長任務前把 Mac 設成「接電源不睡眠」。第一次在新資料夾會問「Trust 這個資料夾?」，練習資料夾答 y，不要在家目錄或含病人資料的資料夾開。

Codex（ChatGPT 桌面版）手機遙控

條件：Plus 以上；Mac／Windows 裝最新 ChatGPT 桌面版；手機裝最新 ChatGPT App，兩邊同一帳號。有學員回報帳號沒開兩步驟驗證時配對會失敗，先到 chatgpt.com 設定 → 安全性開啟 MFA。

  1. 電腦端：選單列「ChatGPT」→「設定」→ 左側往下到「連線」→ 分頁「控制這台 Mac」→ 把「允許連線」打開 → 右上「新增」→ 照畫面指示配對手機。配好的手機會列在下面，隨時可「撤銷存取權」。
  2. 防睡眠：同一頁「其他設定 → 讓這台 Mac 維持喚醒」打開（接電源時有效），不然人一離開電腦睡著就斷線。
  3. 手機端：ChatGPT App → 上方切到 Codex（或「Remote／遠端」分頁）→ 會看到電腦上的 Codex 對話與資料夾，點進去就能下指令、看進度、按允許。這些遠端對話不會出現在手機一般的聊天紀錄裡。
  4. 權限：Codex 桌面版「設定 → 一般 → 預設權限」有三檔；課堂請維持預設（每次改檔都會問）。不要為了手機上少按幾次就開「完整存取權限」。有時允許的提示沒跳到手機上，任務看起來卡住，回電腦按一下就好。
  5. 反過來：同一頁的「控制其他裝置」分頁，是用這台 Mac 去遙控你另一台電腦；「SSH」是給工程師接遠端主機用的，課堂不教。
兩家共同的三條規矩：① 手機要有螢幕鎖，遙控等於把電腦交給拿到手機的人；② 只在去識別化的練習資料夾開遙控；③ 任何「刪除、寄出、送出」都回到電腦前再按。OpenCode 目前沒有官方手機遙控，它的「分享」是公開對話連結，不要拿來當遙控用。手機端的畫面（Claude App 的 Code 分頁、ChatGPT App 的 Codex 分頁）請在課堂上用講師手機投影示範。

先解決上週的問題：麥克風講中文，ChatGPT 跑出簡體字

上週測試：Gemini 轉出來的文字正常，ChatGPT 會出現簡體字。要徹底解決，先弄清楚三個設定各管什麼，因為「記憶」和「自訂指示」只管 ChatGPT 的回覆，管不到麥克風聽寫出來的字。

承接第 1 堂：簡報後製的兩條捷徑（Canva 多頁模板、DeckEdit 文字辨識）

第 1 堂做簡報的流程是「Gemini Notebook／任務產出 → 匯出 PDF → Canva 魔法圖層一張一張改」。魔法圖層一次只收一張圖，十頁簡報要做十次。今天補兩個更快的做法。

ChatGPT＋Canva 應用程式：一次生出多頁、每頁都是可編輯圖層

  1. 左側「外掛程式」→ 搜尋 Canva → 按「＋」，用瀏覽器登入你的 Canva 帳號（免費帳號即可）。裝好後名字旁邊會變成「…」。
  2. 先在對話或專案裡把簡報大綱寫好：8 頁、每頁標題與三個重點、對象是長者。
  3. 回到對話，輸入框打 @Canva，選單第一列選「Canva」，再說：「用上面的大綱做一份 8 頁簡報，大字、高對比、每頁一張插圖位置留白。」
  4. 對話裡會出現預覽。整體要改（全部換成暖色、第 3 頁改短）直接在對話裡說。
  5. 點「在 Canva 開啟」。每一頁的標題、內文、圖片都已經是獨立圖層，不用 OCR、不用魔法圖層，直接點字改字。
  6. ChatGPT 生的插圖（第 8 節）另外下載，在 Canva 裡拖進對應頁面。
和魔法圖層的差別：魔法圖層是「把一張做好的圖拆成圖層」，只能單張；Canva 應用程式是「請 Canva 直接排版」，天生多頁可編輯。缺點是版型由 Canva 的模板決定，沒有 Gemini 任務做出來的那麼有設計感；可以先用 Gemini 任務定調，再把大綱餵給 @Canva 做可編輯版。

DeckEdit：已經做好的 PDF 簡報，用文字辨識（OCR）變成可以改字

第 1 堂介紹過，這裡再放一次步驟，因為它和上面是互補的：Canva 應用程式適合「還沒做」的簡報；DeckEdit 適合「已經做好、只想改幾個字」的簡報。

  1. 打開 deckedit.com/zh-Hant，免費、不用註冊，檔案留在你的瀏覽器裡不上傳。
  2. 拖入 PDF：Gemini Notebook 匯出的簡報、ChatGPT 生的整頁圖片、或 Canva「分享 → 下載 → PDF 標準」。
  3. 等它辨識，每頁的文字變成可點選的文字框；點一段就能改字、放大、換字體。常見用法是把 Notebook 簡報太小的字一次調大。
  4. 匯出 PPTX，交給同事用 PowerPoint 或 Google 簡報繼續。
個資提醒：DeckEdit 在本機跑，可以放院內簡報；Canva 應用程式會把大綱送到 Canva 雲端，只放已去識別化、可公開的衛教內容。

  1. 先拆風格、不畫圖：上傳參考圖，請 AI 把色彩、線條、人物畫法、構圖寫成一段「風格說明」
  2. 存成風格卡：把風格說明存起來，以後每次貼上
  3. 生圖時講清楚角色：「第 1 張只管風格，不要照抄人物和內容」，不寫的話 AI 常把參考圖整個抄過來
  4. 系列在同一個對話做：第一張滿意後說「接下來都用這個風格」
  5. 長期使用放進專案：參考圖＋風格說明放進 ChatGPT 專案或 Gemini 的 Gem（第 14 節）
① 拆風格（三個工具都能用）請分析我上傳的這張圖的視覺風格，先不要畫圖。請用條列寫出： 1. 整體風格（例如扁平插畫、水彩、等距 3D） 2. 主色與輔色（盡量給色碼） 3. 線條粗細與描邊方式 4. 人物畫法（比例、五官、表情） 5. 構圖與留白 6. 文字區塊的位置與字體感覺 最後整理成一段 80 字內的「風格說明」，讓我之後生圖時可以直接貼上。
② 照風格生成新圖卡（Gemini、ChatGPT）第 1 張圖是「風格參考」：只參考它的畫風、色彩、線條，不要照抄裡面的人物和內容。 請畫一張糖尿病衛教圖卡，主題是「每天檢查雙腳 5 步驟」。 對象：65 歲以上長者。直式 4:5。 畫面：一位台灣長輩坐在椅子上檢查腳底，旁邊用 5 個小圖示表示步驟。 文字只放標題「每天看腳 5 步驟」，其他文字我會自己加。 風格說明：（貼上第①步的風格說明）
③ 多張參考圖、分配角色（Gemini 最適合）圖 1：風格參考（畫風與色彩） 圖 2：人物參考（請保持這位衛教師角色的長相與制服） 圖 3：場景參考（門診衛教室） 請用圖 1 的風格，讓圖 2 的人物在圖 3 的場景中，示範胰島素筆的注射部位。 不要加入任何文字。
④ 系列一致（第二張以後）很好，接下來這一系列都用這張的風格、人物和配色，不要改變。 下一張主題：「低血糖時先吃 15 克糖」。
⑤ 鎖住不能變的地方（局部修改）只修改右下角的食物圖示，換成一杯果汁。 人物、背景、配色、標題文字都保持完全不變。

寫作區塊：在 AI 的稿子上直接動手改

不用再說「太抽象了，再改一次」。直接刪、直接補、打個問號，AI 會幫你圓回去。

ChatGPT寫作區塊

  • 提示詞最後加「用寫作區塊」，回答裡會出現標著「寫作」的方框
  • 點方框右上角「展開」，右側變成文件，可直接打字、刪除，也能復原、下載
  • 改完在左邊說「依照我的修改，把整篇順過一次」，新增的字會用粗體標出
  • 2026 年 5 月起，主力模型已用寫作區塊取代舊的 Canvas

GeminiCanvas

  • 對話框「＋」→「更多工具」→「Canvas」，或直接說「用 Canvas 寫」
  • 可直接編輯；反白一段文字，旁邊會跳出「問問 Gemini」，輸入「改白話一點」
  • 右上「匯出」可存成 .md 或存到雲端硬碟，最適合要交出去的稿子

ClaudeArtifacts

  • 說「做成文件（Artifact）」，內容會出現在右側獨立視窗；部分帳號會改用「Claude Docs」文件，看得到 Claude 邊寫邊打字
  • 指定「只改『為什麼能看三個月』那段，其他不要動」，它只會更新那一段
  • 可下載、複製或分享；長文寫作是 Claude 的強項

練習：衛教單張的「半自動」改稿

先請它寫進寫作區塊用 400 字介紹「什麼是糖化血色素（HbA1c）」，對象是剛確診的民眾，盡量條列，放在寫作區塊裡（ChatGPT 說「用寫作區塊」、Gemini 選 Canvas、Claude 說「做成文件」）。

接著直接在稿子上：刪掉你覺得多餘的句子；在想補的地方打「：（這裡補充多久驗一次）」；最後請它「依照我的修改，把整篇順過一次，改過的地方標出來」。

學習模式：讓 AI 當你的家教，不是給答案的機器

先確認你懂到哪裡，再用蘇格拉底式提問一步步帶你想。這是最被低估的功能。

ChatGPT學習模式

名詞解釋：API 和 MCP 是什麼？外掛背後就是它們

學員常問「外掛、連接器、應用程式、MCP、API」到底是不是同一件事。一句話：API 是兩個軟體之間的「插座規格」，MCP 是專門給 AI 用的「萬用轉接頭」。你在第 12 節點的那些外掛，底下跑的多半就是 MCP。

API（應用程式介面）

  • 一個軟體開放給別的軟體「照規格來叫我做事」的入口。你按網頁按鈕是人用介面；程式之間就用 API。
  • 衛教師會碰到的兩種：① 模型 API：OpenCode 的「金鑰（API key）」就是這個，付費計次（A 節）。② 服務 API：Google 日曆、PubMed、Canva 都有，程式才看得懂。
  • 金鑰等於密碼：不要貼進聊天視窗、不要寫在共用文件；外洩就去原網站撤銷重發。

MCP（Model Context Protocol，模型內容協定）

  • 2024 年底由 Anthropic 提出、2025 年起 OpenAI 與 Google 也採用的共同規格：工具商只要做一個「MCP 伺服器」，ChatGPT、Claude、Gemini、OpenCode 都能接。
  • 每個 MCP 伺服器提供幾個「工具」（例如「搜尋 PubMed」「讀取雲端硬碟檔案」），AI 看到你的要求，自己決定要不要呼叫。
  • 三家叫法不同、本質一樣：ChatGPT 的外掛程式、Claude 的連接器、Gemini 的應用程式，以及 OpenCode 設定檔裡的 mcp 區段。
  • 和技能的差別：技能是「教 AI 怎麼做」（文字 SOP），MCP 是「給 AI 一雙手」（真的能去抓資料、建檔案）。

名詞解釋：瀏覽器控制、Chrome 控制、桌面控制、背景控制，差在哪？要先設定什麼？

這四個詞都是「讓 AI 替你動手」的不同範圍。從小到大：一個網頁 → 你的整個 Chrome → 任何桌面程式；「背景／全螢幕」則是桌面控制的兩種模式。

名稱AI 能碰到什麼誰有適合風險
瀏覽器控制（雲端瀏覽器）AI 自己在雲端開一個瀏覽器，讀網頁、點按鈕、填表。不是你的瀏覽器，沒有你的登入狀態。ChatGPT「雲端瀏覽器」（Agent 模式）、Gemini Agent 模式公開網站查資料、比價、填公開表單要登入的網站得在它的瀏覽器重新登入；資料經過雲端
Chrome 控制（Claude in Chrome）裝一個擴充功能，AI 操作你自己的 Chrome：看得到你已登入的 Gmail、學會網站、院內系統。可讀 DOM，比看截圖快又準。Claude（擴充功能）；ChatGPT 的 Atlas 瀏覽器是同類學分查詢、報名、整理你個人帳號裡的東西（院內系統依資安規定，預設不開放）它用的是你的身分；每個網站第一次會問你允不允許
桌面控制（Computer use）截圖、移滑鼠、點、打字，多數桌面程式都能操作：Excel、PowerPoint、OpenCode、LINE（瀏覽器只能看、終端機只能點，不能打字）。Claude 桌面版（Cowork／Code）、OpenCode 與 Claude Code 的 computer-use、Codex 桌面版沒有網頁版、沒有 API 的老程式；跨程式的流程最強也最危險：它看得到螢幕上一切、能按任何鍵
背景控制 vs 全螢幕控制
桌面控制的兩種模式		背景：只對你授權的那一個程式視窗操作，不搶滑鼠，你可以繼續用別的程式。全螢幕：接管整個螢幕與鍵盤，邊緣會發光，你要停手等它做完。Claude 桌面版的授權對話框會讓你選背景：單一程式的重複工作。全螢幕：要跨程式、拖拉、或背景模式點不到的時候背景模式下通常不會互相干擾，但目標視窗被蓋住就會點錯；全螢幕模式下千萬別同時動鍵盤

上課前要先做好的設定（Mac 為例）

  1. 系統權限：系統設定 → 隱私權與安全性 → 「輔助使用」「螢幕與系統錄音」「自動化」都加入 Claude（或 OpenCode）。沒給就只能截圖、不能點。
  2. Chrome：安裝「Claude in Chrome」擴充功能並用同一個 Claude 帳號登入；釘選在工具列。
  3. 第一次授權：AI 要操作某個程式或網站時會跳對話框，列出它要碰的程式；這裡選「背景」或「全螢幕」。瀏覽器類程式只給「唯讀」、終端機類只給「點擊」，是系統預設的保護。
  4. 桌面空間：把要給 AI 操作的程式放在同一個一般桌面，不要用全螢幕模式（綠燈放大）的桌面：視窗搬不進全螢幕空間，背景模式就點不到。
  5. 清場：關掉會蓋住目標視窗的其他程式（被蓋住的地方點不到）、關掉含病人資料的視窗、先開好去識別化的練習資料夾。
  6. 舊任務：OpenCode／Claude Code 若有「已中斷」的舊工作階段，先開新的工作階段再交辦，避免舊任務被重新觸發。

彼此怎麼搭配、怎麼選

  • 先問「這件事在哪裡發生」：在網頁上 → Chrome 控制（要你的登入）或雲端瀏覽器（公開網站）；在桌面程式 → 桌面控制；在資料夾 → 根本不用控制，交給 OpenCode 直接讀寫檔案最穩。
  • 同一件事可以接力：例：Chrome 控制到學會網站查學分 → 桌面控制打開 Excel 登記 → OpenCode 把登記表轉成月報。各做自己最擅長的一段。
  • 能用 API／MCP 就不要用控制：控制是「看畫面、點按鈕」，慢且會點錯；Google 日曆、雲端硬碟、Canva 都有連接器，直接接。控制留給沒有接口的系統。
  • 背景優先，全螢幕備用：背景模式你不會被打斷；真的點不到（視窗被蓋、在別的桌面）再切全螢幕，做完就收回。
講師實測踩到的三個坑（2026/11）：① 目前桌面是全螢幕 App，OpenCode 視窗搬不過來；② ChatGPT 桌面程式的視窗蓋在 OpenCode 上面，點擊被擋；③ OpenCode 舊的「已中斷」工作階段被重新觸發，開始跑原本的任務，要立刻按停止。所以上面第 4、5、6 條不是客套話。
第 12 節帶走三句話：外掛＝讓 AI 伸手進你的工具，權限一律先選唯讀；三家名稱不同（外掛程式／連接器／連接器與技能），做的是同一件事；「瀏覽器控制、Chrome 控制、桌面控制」差在誰的電腦、看得到什麼，涉及登入帳號的只用自己的手按送出。

AI 可以幫你「找、讀、整理、反問」，不能替你「決定」。這一節把界線和做法一次講清楚。

可以交給 AI 的

  • 找文獻：用 PubMed 類外掛或研究模式，依 PICO 找近 5 年的指引與系統性回顧

  • 個別病人的診斷與處置決定：AI 只能給「可能要考慮的方向」，決定由醫療團隊依院內流程做

怎麼問才精準

  • PICO 四個都寫，族群要寫年齡與疾病型別，介入要寫「誰做的」（護理師主導），結果要寫可測量的指標。
  • 限制條件外顯：年份、研究設計（RCT／系統性回顧／指引）、篇數上限、語言。
  • 輸出欄位外顯：作者年份、期刊、設計、樣本數、一句結果、PMID 或 DOI；沒有識別碼的一律不採信。
  • 逼它誠實：「找不到就說找不到」「部分符合要說明哪裡不符」「交代實際搜尋字串」。
  • 英文關鍵字效果較好：中文問沒關係，但可以附一行英文關鍵字（older adults, nurse-led, diabetic foot, self-care, RCT）。

用這類外掛要注意

  • Consensus 不是 PubMed：索引以英文、有摘要的論文為主，不含你醫院訂閱的全文；它的「Consensus Meter」（多少篇說是／否）由 AI 判讀，可能反映出版偏差，當線索不當結論。
  • 年齡陷阱：摘要常只寫平均年齡，「平均 67 歲」不等於「全部 65 歲以上」，要看納入條件；PubMed 的 Aged 標籤也一樣。
  • PMID 一定回查：這次兩邊都沒編造，但任何一次都可能；回查花 30 秒，引用錯誤的代價是整份報告。
  • 額度：Consensus 免費帳號有每月次數上限，Deep Search 更少；課堂練習一人一兩次夠用。
  • 它給的是「定向查找」不是系統性檢索：要寫文獻回顧，拿它的布林式到 PubMed、Cochrane 重跑，並記錄日期與篇數。

Q1 醫學、健康資料要怎麼查才精準？

上傳前先瘦身：用 MarkItDown 把 PDF 轉成文字

同一份指引，轉成文字再給 AI，額度用得少、回答更專心，上傳前還能先看一遍有沒有個資。

為什麼要先轉？

  • 一頁算兩份：直接上傳 PDF 時，Claude 會把每一頁轉成圖片看一次、再抽文字讀一次，兩份都算額度。官方估算光文字每頁就約 1,500～3,000 token，圖片另計。
  • 差距很大：一份 3 頁的文字型 PDF，連圖讀約 7,000 token，只讀文字約 1,000 token，省下七成以上。30 頁的指引直接上傳，可能一次吃掉近 10 萬 token。
  • 額度用完要等：上傳的附件越大，越快碰到用量上限，只能等重置。
  • 醫療場域多一個好處：轉成純文字後，你能先打開看一遍、搜尋姓名與病歷號，或貼進去識別化工作台檢查，再交給 AI。

MarkItDown 是什麼

微軟推出的免費開源小工具，把 PDF、Word、PowerPoint、Excel 轉成 Markdown 純文字。標題、條列、表格會保留成 AI 好讀的格式。

  • 在自己的電腦上轉檔，檔案不會先傳到雲端
  • PowerPoint 特別值得轉：Claude 的上傳清單不收 .pptx
  • OpenCode 可以直接幫你裝、幫你整個資料夾一起轉

常見疑問：「聽說現在上傳 PDF 跟 Markdown 已經沒差了？」

說法對不對實際狀況
「不要上傳 PDF，要給 Markdown」一半對問一次就丟的小文件（10 頁內、純文字），直接上傳 PDF 沒問題，三家都讀得懂。要反覆用（放進專案、給代理、每週重讀）的文件才值得先轉。
「已經沒差異了」讀得懂沒差，花費有差模型抽文字的能力確實進步了。差異剩在 token：PDF 會多算一份圖片、版面表格常被打散；Markdown 只算文字，標題和表格保留。同一份 30 頁指引，差 3～7 倍額度。
「差異在 token」對，還有兩個① token：上面那張表。② 檢查個資：純文字你能先搜尋姓名、病歷號再上傳，PDF 很難。③ 代理工具：OpenCode 等資料夾代理本來就只讀文字檔，PDF 要先轉才碰得到。

一句話：聊天視窗偶爾問，PDF 直接丟；要省額度、要查個資、要給代理，先轉 Markdown。

哪些檔案該轉？

檔案建議衛教師常見例子
文字為主的 PDF轉臨床照護指引、會議記錄、評鑑條文、公文
PowerPoint轉院內教育訓練簡報、別人分享的衛教簡報
Word、Excel都可以品質指標模板直接上傳也行
圖表很多的 PDF別轉食物份量圖、衛教圖卡、流程圖：轉了圖就不見
掃描的 PDF別轉紙本掃描的轉診單、舊版單張：預設不辨識圖片裡的字，會轉出空白
超過 100 頁差不多此時 AI 本來就只抽文字，轉不轉差異小

GitHub 是什麼？

全世界工程師放檔案的雲端倉庫。我們只用它其中一個免費功能：GitHub Pages，把 HTML 檔變成一個公開網址。

為什麼要學？

AI 做出來的網頁、簡報、衛教小工具都是 HTML 檔。放上 GitHub Pages，用手機、LINE 分享一個連結就能打開，不用寄檔案。這份講義就是這樣放上網的。

要花錢嗎？

不用。免費帳號就能做公開網頁，不需要信用卡。要準備的只有一個 Email 和 20 分鐘。

步驟一：註冊 GitHub（5 分鐘）

  1. 打開 github.com/signup
  2. 輸入 Email、設定密碼
  3. 設定 Username（使用者名稱）：這會變成你的網址，例如 username 是 tyh-dm-amy，網址就是 tyh-dm-amy.github.io。只能用英文小寫、數字、減號，取好記、專業一點的
  4. 完成真人驗證，到信箱收 GitHub 寄來的驗證碼，貼回網頁
  5. 選方案時選 Free；問卷可以直接略過
  6. 建議到右上頭像 →「Settings」→「Password and authentication」開啟兩步驟驗證
名字想清楚再取：username 之後可以改，但網址會跟著變、舊連結會失效。不要用身分證字號、生日這類個資當名字。

步驟二：請 AI 做一個自我介紹網頁（5 分鐘）

三個對話工具都可以。Claude 會直接在右側顯示做好的網頁，最方便預覽；ChatGPT 和 Gemini 會給一段程式碼，也一樣能用。

個人網頁提示詞（改成你自己的資料）請幫我做一個單一檔案的 HTML 自我介紹網頁，檔名 index.html，所有 CSS 寫在同一個檔案裡，不要用外部圖片。 我的資料： - 稱呼：（例如 王衛教師、Amy） - 單位：衛生福利部桃園醫院 糖尿病中心 - 職稱與證照：（例如 護理師、糖尿病衛教師） - 擅長的衛教主題：（例如 胰島素注射、足部照護、低血糖處理） - 一句話介紹：（例如 用長輩聽得懂的話，陪你把血糖顧好） - 聯絡方式：（只放公務信箱，或寫「請洽糖尿病中心櫃台」） 設計要求： 1. 手機打開也好讀，字大、行距寬，適合長者 2. 配色溫和，用淺綠或米白 3. 用文字或圖示代替照片 4. 最下方放「本頁使用 AI 協助製作」 做好後請告訴我怎麼存成 index.html。

Claude存檔

右側網頁上方按「下載」，或點「程式碼」分頁全選複製。檔名改成 index.html。

ChatGPT存檔

程式碼方框右上「複製」，貼到記事本，存成 index.html。也可以請它「直接給我下載檔案」。

Gemini存檔

步驟三：上傳到 GitHub Pages（10 分鐘，全程用網頁，不用寫程式）

  1. 登入 GitHub，右上「＋」→「New repository」（新增倉庫）
  2. Repository name 一字不差填 你的username.github.io，例如 tyh-dm-amy.github.io。這個特別的名字會讓 GitHub 自動把它變成網站
  3. 「Choose visibility」選 Public；「Add README」保持 Off → 按綠色「Create repository」
  4. 出現的頁面中間找到藍色小字「uploading an existing file」，點進去
  5. 把 index.html 拖進「Drag files here」框框 → 下方保持「Commit directly to the main branch」→ 按綠色「Commit changes」
  6. 等 1～2 分鐘，打開 https://你的username.github.io，看到你的網頁就完成了
  7. 沒出現？到倉庫上方「Settings」→ 左側「Pages」，確認 Source 是「Deploy from a branch」、Branch 是「main」→「/ (root)」，按 Save 再等 1 分鐘
