優缺點（白話版）

優點：不用學 GitHub、不用再辦帳號，一分鐘就有網址；網址名稱可以自己取、可以印 QR；之後可以在協作平台裡再加頁面、導覽列、嵌 Google 表單；院內 Workspace 帳號可以設「只限機構內的人看」，這是 GitHub 公開頁做不到的。

缺點：① 像被放進相框：協作平台不是直接顯示你的網頁，而是在它自己的頁面裡開一個「窗」把你的網頁嵌進去，所以最上面會多一條協作平台的標題列；網頁很長時，要在那個窗裡再捲動一次（可在編輯器把窗拖高）。② 再匯出是「另一個網站」：在 Gemini 改好內容再按一次匯出，會多出一個全新的網站、新網址，舊網址還是舊內容；要更新得進協作平台改，或重新匯出後重發 QR。③ 網址不是你的：一律 sites.google.com/view/…；院內 Workspace 管理者有權限整個關掉對外發布。

怎麼選：今天先做出來給人看、或只給院內同事看 → 協作平台最快。要印成 QR 貼衛教室、要常常改、要把簡報、九宮格、報名表都放在同一個首頁 → 「匯出 → 下載程式碼」拿到 HTML 檔，走 GitHub 五步驟：網址固定，改好重傳同名檔案就更新。兩邊可以並存：協作平台給院內，GitHub 給病人。

Excel × AI：六種搭配，從「幫我寫公式」到「整批檔案一次處理」

衛教師每天都在開 Excel。AI 不是要取代它，而是把你卡最久的那幾步接走。由淺到深六種，前三種今天就能用。

用法怎麼做衛教師例子適合工具風險與對策
① 寫公式、解釋公式
最安全、最常用		把需求用中文講，或把看不懂的公式貼給它「A 欄是 HbA1c，B 欄是日期，幫我寫一個公式：近 90 天內 HbA1c<7 的人數」「這段 VLOOKUP 在做什麼？」三家都行；Gemini 對 Google 試算表函數最熟公式貼回去前，拿 3 筆已知答案的列驗算

Excel 本身的 AI、以及 Google 試算表

  • Microsoft 365 Copilot in Excel：在 Excel 右側對話，可直接對選取範圍做公式、分析、圖表。需 Microsoft 365 Copilot 授權（多為企業方案），院內多半沒有；若院內已授權且資安單位核可，資料留在院內租戶，較容易符合規範。
  • Google 試算表 ＋ Gemini：右上「Gemini」側欄可問資料、做表；儲存格裡可直接用 =AI("把 A2 的症狀描述分類成 低／中／高 風險") 這類函數；第一格按「生成並填入」後，往下拉整欄會自動顯示「生成中…」並逐格算出（僅供練習分類，不可取代臨床分級）。免費 Google 帳號可用部分功能。
  • Excel 沒有 Copilot 時：就是本節的做法：另存一份去識別化的檔，丟給 ChatGPT／Claude／Gemini，再把結果貼回。

上傳 Excel 前的三件事

  1. 去識別化：刪掉姓名、病歷號、身分證、電話、出生日期；用「個案代號」取代。第 1 堂的工作台可以自動做。
  2. 瘦身：只留需要的工作表與欄位；刪掉隱藏工作表、備註行、合併儲存格（S 節「乾淨表」規格）。
  3. 說清楚：第一句話告訴它「哪張工作表、哪幾欄、每欄是什麼意思、單位」。AI 讀不到你的欄位定義表，就會猜。
通用開場（貼在任何 Excel 任務前面）附件是去識別化的合成資料。只看工作表「原始資料」。欄位說明：個案代號（文字）、季別（2026Q1 格式）、HbA1c(%)（數值，合理 4–15）、收縮壓／舒張壓（mmHg）、LDL(mg/dL)。 做任何修改前先列出你打算改哪些儲存格；產出新檔時保留原工作表不動，結果放新的工作表。每個公式都用文字說明一次用途。

實際跑一次：ChatGPT 寫公式、解釋公式（2026 年 11 月，課程模板）

工作模式。兩個任務各花約 1 分鐘。

課堂體驗（10 分鐘）：三個小任務，用課程模板

  1. 寫公式：「在『原始資料』工作表，幫我寫一個公式算 HbA1c<7 的比例，分母排除空白。」把公式貼進 Excel，和它說的數字對一次。

延伸：用 AI 做描述性統計，怎麼確保數字是對的

時間夠再上。接在 Ⓐ 之後：平均、百分比、分組計數看起來最簡單，卻是最常「算錯而沒人發現」的地方。

為什麼會錯：AI 有兩種「算」

  • 用看的算（心算）：模型把表格當文字讀，直接「想」出一個平均。小表可能對，列數一多就會漏列、看錯欄、把 7.5 讀成 75。這是幻覺的來源。
  • 寫程式算：模型寫一段 Python，由程式真的去加總。數字由程式產生，模型只負責寫程式和解讀。這條路才可靠。
  • 三家在哪一條路：ChatGPT 工作模式與「進階資料分析」會跑程式；Claude 開「分析工具」（設定 → 功能）；Gemini 會自動執行程式碼；OpenCode 本來就在跑程式。看到它顯示程式碼或「正在分析」，才代表它真的算了。

Excel 還是 CSV？差別不在格式，在「乾不乾淨」

  • Excel 出錯的原因：多個工作表、合併儲存格、標題在第 3 列、備註行夾在資料中、公式與隱藏欄、數字存成文字、單位寫在格子裡（「7.5%」）。AI 讀錯範圍，數字就全錯。
  • CSV 為什麼穩：只有一張表、第一列就是欄名、沒有公式、沒有格式。所以「改用 CSV」有效，但真正有效的是「一個檔一張乾淨的表」。
  • 乾淨表的規格：第一列欄名（不重複、不含空白與單位）、一列一筆、數字欄只有數字、日期統一 YYYY-MM-DD、缺值留空不要填「無」或「-」、沒有合併儲存格、沒有小計列。
  • 非用 Excel 不可時：指定「只讀『資料』工作表，A1 到 H301」，並請它先印出讀到的前 5 列給你看。
直接上傳 Excel（.xlsx）另存成 CSV

多個工作表最常出事的地方：有的只讀第一張、有的全部讀進來混在一起、有的問你要哪一張。說明頁、樞紐表、圖表工作表都可能被當成資料不會有這問題：CSV 天生只有一張表（另存時 Excel 也只存目前這一張）
公式、合併儲存格、格式公式可能讀到結果也可能讀到空值；合併儲存格會讓欄位錯位；「7.5%」可能被讀成 0.075 或 7.5只剩純文字和數字，所見即所得
檔案大小、額度同樣內容比 CSV 大好幾倍，大檔容易逾時或吃掉上傳上限最小，880 列不到 50 KB
中文亂碼不會用 Excel「另存新檔 → CSV UTF-8（逗號分隔）」才不會；選到舊的「CSV（逗號分隔）」中文可能變亂碼
結論多張工作表、有格式的原始檔：先整理，只留一張乾淨的資料表再上傳，或在提示詞指名工作表與範圍第一次算、要出數字給主任看，用 CSV。本節的練習檔兩種都提供，就是讓你試一次差異
多分頁 Excel 的安全做法（三步）：① 在 Excel 把要分析的那張工作表右鍵「移動或複製 → 建立複本到新活頁簿」；② 新活頁簿裡刪掉標題列以上的說明、小計列、合併儲存格；③ 另存成「CSV UTF-8」再上傳。若一定要整本上傳，提示詞第一句寫：「這個檔有 N 張工作表，只分析『個案資料』這張，其他工作表忽略；開始前先告訴我你讀到幾列幾欄、欄名是什麼。」

#要它做的事抓什麼錯
1先描述資料再算：幾列幾欄、每欄名稱與型態、每欄缺值數、數值欄的最小／最大值讀錯範圍、讀錯工作表、7.5 變 75
2顯示程式碼與程式輸出，每個數字旁附程式印出的原值確認是「算的」不是「想的」
3每個比例寫明分子與分母，以及分母排除了誰達標率的分母用錯（全部病人 vs 有檢驗者）
4異常值先列出、不要自動排除，排除與否由你決定並記錄它「好心」把 1380 丟掉，你不知道
5缺值處理方式明說：忽略、補 0、補平均，三者結果差很多平均值被缺值補法改變
6分組統計時附每組人數 n，n 小於 10 的組標記一組只有 3 個人卻拿來比較
