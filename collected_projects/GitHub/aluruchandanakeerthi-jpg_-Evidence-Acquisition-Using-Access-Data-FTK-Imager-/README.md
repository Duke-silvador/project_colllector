# Project: aluruchandanakeerthi-jpg/-Evidence-Acquisition-Using-Access-Data-FTK-Imager-

**Source:** GitHub

**Description:** This experiment demonstrates the process of acquiring digital evidence using AccessData FTK Imager. FTK Imager is a forensic imaging tool used to create forensic copies of storage devices, partitions, and other digital media while preserving the integrity of the original evidence.
