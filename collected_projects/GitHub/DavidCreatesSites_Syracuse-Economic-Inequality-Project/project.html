Context around the project

This research project, created by David Duru, aims to educate readers and encourage local government to address the problems documented in the evidence. It brings together public data about education, employment, housing, health, and unequal outcomes in Syracuse.

The main Project Details page introduces the work. The topic pages connect findings with interactive data displays, explanations, and source citations. Statistical data can be added and updated as the research develops.
