01 / Context

The project

Context Around the Project

This website brings together public data about Syracuse’s income, education, employment, housing, and neighborhood conditions. Interactive charts connect the evidence with transparent sources and clear explanations.

This research project, created by David Duru, aims not only to educate but also to serve as a call to action for local government to address the problems discussed in the evidence. Statistical data will be added and updated over time.
