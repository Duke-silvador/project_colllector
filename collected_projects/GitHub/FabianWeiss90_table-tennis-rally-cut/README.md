# Project: FabianWeiss90/table-tennis-rally-cut

**Source:** GitHub

**Description:** Automatic rally detection and cutting for table tennis videos filmed from behind the table. C++ tool with GPU acceleration (AMD, NVIDIA, Intel) on Linux and Windows: aligns pre-cut videos to originals for frame-accurate annotation, extracts visual features, detects rallies with an MS-TCN model and cuts 4K footage. Non-commercial.
